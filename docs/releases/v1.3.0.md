# 課程學習站 v1.3.0

本版整理 v1.2.0 之後累積的題庫、匯入、搜尋、練習與管理功能，並同步更新 README 與網站入口。

## 題庫與閱讀

- 整理挖寶單元、記憶體管理與演算法 L7 等單元的主題、題型排序及解析；計算題補充解題步驟。
- 全站閱讀題庫依單元、主題排序，同主題按單選、多選、填空排列；最新投稿同步後也套用排序。
- 改善中英題幹、填空標記、數列搜尋與圖題比對；原題文字、題圖與老師指定答案保留。
- 加入完整題庫快照、瀏覽器快取及背景同步，顯示同步來源、最後同步時間與失敗提示。

## 匯入、投稿與批次查題

- 可配對題目 HTML 與交卷結果 HTML，支援挑選下載時附帶的題圖。
- 匯入預覽自動建議主題，可勾選本批題目整批修改；後續批次展開時才建立編輯欄位。
- 改善填空標記、題號前綴、雙語內容、答案配對及重複檢查，並顯示新增與重複題數。
- 批次查題只有已收錄與未收錄；完整符合才帶入答案，不以相似題猜測答案。
- 未收錄題目顯示原因，並可並排比較候選版本的題幹、選項、填空數與答案內容。

## 練習與單元測驗

- 遮答練習與單元測驗支援選項隨機排列並同步對應正解，相依選項保留原序。
- 解析中的選項代號改以選項內容說明，降低選項換序造成的混淆。
- 未交卷測驗自動暫存題目、選項順序與作答，重新整理後可繼續。
- 每科保留最近一次已交卷結果；重新設定不會刪除，可篩選錯題、未作答並直接重練。

## 題庫管理

- 投稿及題目修正立即公開，管理者可查看歷史、退回上一版或原始版。
- 提供題目勾選、批次移除與還原，已移除題目保留復原機制。
- 新增題庫健檢，列出缺解析、缺答案、答案無法對應選項及疑似重複題。
- 疑似重複版本可並排比較、開啟任一版本編輯；不自動覆蓋或刪除。
- 可主動檢查題圖連結並停止檢查；無法載入只標示無法確認。
- 保留投稿服務原有管理樣式，改善深色模式與窄版顯示。

## 驗證與使用說明

- 最近一次功能整合的 **159 項相關測試通過**，投稿／管理服務成功建置。
- 已實測測驗還原、錯題重練、整批主題修改、版本比較及深色模式；未對公開題庫寫入測試資料。
- 本版功能已發布到閱讀網站及獨立投稿／管理服務；GitHub Release 的原始碼壓縮檔不是線上資料庫備份。
- 測驗與學習紀錄存在目前瀏覽器；不會跨裝置同步。
- 本版未加入每個主題的學習進度。
