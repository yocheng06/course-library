# 訪客設備資訊呈現

將設備類型、系統、瀏覽器及型號分開顯示。Windows 等電腦瀏覽器未提供型號時，明確解釋無法得知電腦品牌、型號或區分桌機與筆電；iPhone／iPad 僅辨識系列，不推測世代。已知的 Android 型號直接顯示在訪客摘要。

Android 除既有 Sec-CH-UA-Model 外，也接受舊版 User-Agent 中明確位於 Build/ 前的型號，拒絕精簡 UA 的 K、unknown 等泛稱。未增加請求的 Client Hints、硬體指紋、原始 UA 儲存欄位、保留時間或封鎖規則。原有瀏覽器分組、暱稱與已知型號保留方式不變。資訊為瀏覽器回報，不能證明實體設備或使用者身分。

測試涵蓋 Windows 不採用手機型號提示、兩種舊 Android UA、精簡 UA 不產生假型號、iPhone／iPad 不猜世代與既有封鎖流程。

發布前檢查：486 項前端、86 項服務權限、7 項 Cloudflare 移植測試全數通過。既有訪客資料不回填猜測的硬體型號；備援方式只適用於後續瀏覽器已明確提供的資訊。
