## 資料與驗證

- 從原站完整備份還原 722 筆公開題目資料（含已移除及合併資料）、99 筆投稿、404 筆修改歷史、168 筆內建題覆寫、10 筆舊勘誤，保留原 ID、老師答案與狀態。

- 新舊公開 API 比對：作業系統 384 題及 34 筆覆寫、演算法 25 題及 81 筆覆寫；題目 ID、題幹、選項及答案一致。這是移植備份當下的數量，非固定網站題數。

- 獨立 Worker 不信任來自使用者的 `oai-*` 身分標頭；秘密不提交 GitHub。管理設定碼由站主自行輸入且只能使用一次。

已在新站確認管理員登入、管理清單與原始修改歷史可讀；一次性設定碼已撤除。既有重複題投稿測試回傳 `duplicates_only`、新增 0 題。

## 重用與回復

部署與備份步驟見 [Cloudflare 移植說明](../../contribution-service/CLOUDFLARE-MIGRATION.md)。完整備份、SQL、正式設定與題圖匯入包只保存在本機忽略目錄，不放進公開 Repository。

原服務暫時保留供核對；新舊服務是獨立資料庫，切換後應只使用新入口，不能假設兩邊會自動同步。若有人在原站於備份之後新增內容，必須先比對再補入，不能重跑完整 SQL 覆寫已有資料的新資料庫。
