# 題庫服務網址改名（2026-11-18）

站主指定將 Cloudflare 帳號子網域改為 `orange06.workers.dev`。題庫服務新網址為 https://course-library-submissions.orange06.workers.dev ，管理入口為 `/review`。Cloudflare 帳號下於改名前確認只有此一 Worker，並確認指定名稱可用。

主站連結、公開快照、解析中的題圖參照、跨站主題設定與本機部署設定一起更新。題圖儲存 key 與內容不變；改名前先匯出正式資料庫到本機忽略目錄，再於獨立 SQLite 校驗只改變題圖網址，保留所有其他欄位、老師答案、題號、版本、歷史、管理密碼與加密手機驗證設定。

可重用的 `contribution-service/scripts/prepare-service-rename.mjs` 從備份產生只更新題圖網址的 SQL，拒絕使題幹或答案改變的操作；不重建或清空正式資料庫。完整備份與實際資料修正 SQL 不提交 GitHub。

Cloudflare 改名會停止舊子網域的路由，且新子網域可能需要數分鐘才生效；不能假設舊網址會自動轉址。變更後請更新書籤。管理者需在新網址重新登入，原帳密與手機驗證保持有效；原網址的瀏覽器 cookie 不會移至新子網域。

改名前另修正單元設定初始化：不跨 Worker 請求保存 D1 Promise，初始化完成後才標記就緒；公開題庫未知錯誤僅在伺服器記錄名稱與摘要，不回傳內部細節。已重新確認兩科 API 正常。快取版本也納入服務網址，避免新站收到舊站 ETag 後回傳 304，留下失效的題圖參照。
