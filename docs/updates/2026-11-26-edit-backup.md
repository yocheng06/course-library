# 閱讀頁共同編輯、解析與歷史備份

本次處理需求清單第 1、2、4 項；不改批次同步提示、不新增瀏覽器端到端測試。

## 閱讀頁共同修改

原題與投稿題的儲存若回傳版本衝突，讀取最新版並以欄位顯示「你的編輯／題庫最新版本」，保留原輸入與下載入口。必須先載入最新版再手動合併；後續送出使用新版 revision／sourceHash。比較內容以純文字呈現。

修改草稿存在目前瀏覽器 localStorage，以科目與分頁編輯代號分開；重新整理同一分頁可恢復，不會把另一分頁的草稿蓋掉。載入時也比較 sourceHash，避免內建題 revision 相同但原始版本已更新。儲存成功才刪除草稿。瀏覽器拒絕儲存時提示下載；清除網站資料仍會刪除草稿。

## 解析

先於正式 D1 讀取現有版本，再依單元逐批重寫 21 題解析。內容及版本記於 `content/reviewed-explanations-20261126.json`。題幹、選項、答案、圖片及其他欄位保留；不以權威用語解釋答案。條件有差異時列出反例或必要假設，例如 PCB 與 stack、RM 計算得到 75 但原填答 (80)、指數函數的二次上界。

## 兩種備份

- 每週獨立 D1 備份：將既有八張題庫相關表、schema、題圖原始位元組與內容雜湊保存為歷史版本，再從保存的版本還原到測試表。通過才標為有效，保留最近 12 代有效版本及 3 代失敗嘗試；失敗不輪替有效版本。此處不包含完整管理帳號、安全與訪客資料，不能當成完整 D1 備份。管理頁顯示有效代數。
- 完整 D1 SQL 備份：使用官方 Wrangler 匯出全部資料表，在隔離 SQLite 實際還原、檢查歷史及每張題圖，再寫入專案外的私有目錄。檔案權限 0600、目錄 0700，保留最近 12 代；匯出或驗證失敗不刪舊備份。包含敏感管理資料，不能放進 GitHub 或公開下載位置。

不啟用 R2。每週排程仍是台北時間星期一 04:30；每日清理排程維持原設定。

### 完整備份的可複用流程

已登入 Wrangler 的執行環境中（Node 24）：

```sh
XDG_CONFIG_HOME=/workspace/.config node scripts/archive-d1-backup.mjs /workspace/private-course-backups
```

也可驗證並保存已有的完整 SQL：

```sh
node scripts/archive-d1-backup.mjs /私有且持久的備份目錄 /私有位置/database.sql
```

命令列流程目前需手動執行，沒有宣稱自動跨帳號備份。`/workspace` 的檔案仍受此工作環境生命週期影響，請將私有備份目錄複製到自己持有的持久儲存設備；每週獨立 D1 仍在相同 Cloudflare 帳號，也不能防止帳號整體遺失。

### 檢查較早的每週題庫版本

先將 `course-library-restore-check` 用 Wrangler 匯出到私有 SQL 檔，再離線執行：

```sh
node scripts/restore-content-archive.mjs /私有位置/sandbox.sql /私有位置/restored-content.sql 版本時間戳
```

省略時間戳時選最新通過的版本。工具會驗證所有分塊、筆數、雜湊，再建立隔離 SQL 並檢查歷史及題圖；不會寫入正式 D1，也不會覆寫已存在的輸出檔。真正切換正式資料前，應先檢查要復原的題目與後續修改。

## 正式資料驗證與排程狀態

GitHub 已同步，Cloudflare 與 D1 的 21 題解析已發布並重新讀取確認。使用正式 D1 連線執行同一個 `runBackupRestore`，獨立備份庫成功保存兩代有效版本，再從保存內容實際重建及逐表比對：1,001 筆公開／隱藏題目紀錄、552 筆修改歷史、227 筆內建題修改、31 張題圖全部通過。合併讀寫後，實測 SQL 敘述由 77 個降至 45 個（30 次 D1 API 往返），並保留舊版本。

雲端 D1 對 compound SELECT 的限制比本機 SQLite 嚴格，因此每組最多兩個 SELECT；來源資料以同一個 D1 transactional batch 讀取。只查明列的八張題庫表，避免對 Cloudflare 內部表執行 schema pragma。驗證庫結構相同時清空測試內容再還原，結構不同才重建；兩者都不會清除歷史備份分塊。

每週排程設定已由 Cloudflare API 重新讀取確認，但本次觀察期間未收到新的排程事件。上述實測是直接執行相同模組，不宣稱排程已實跑。臨時每分鐘測試排程已移除，只保留每日清理與每週備份；首次排程實跑仍待追蹤。

兩代雲端歷史備份已另行匯出為私有 SQL，透過 `restore-content-archive.mjs` 分別選取舊代與最新代，均在隔離 SQLite 還原通過，31 張題圖及 552 筆歷史一致。新增每週流程 SQL 預算與驗證庫結構變更的測試，確認既有結構可重用、不相容的結構可重建。
