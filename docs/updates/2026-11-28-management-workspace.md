# 管理者專區操作整理

## 使用方式

- 固定五個入口：題目管理、匯入紀錄、課程與單元、訪客與封鎖、系統設定。
- 題目管理預設開啟全部題目；依科目、單元及關鍵字找題。
- 需要處理集中資料完整性與投稿待核對入口；資料完整性沿用題目清單選定的科目、單元。
- 一般題目清單不再重複顯示來源、長 ID 與公開中狀態。詳細資料保留在編輯器。
- 勾選題目後顯示批次工具；勾選全部結果仍包含未載入的結果。
- 桌面寬度至少 1200 px 時使用右側編輯面板，清單可繼續操作；較窄畫面使用對話框，手機使用全頁編輯。
- 上一題／下一題依目前已載入的篩選清單移動；切換前保存本機草稿，不會自動公開。儲存失敗或本機草稿保存失敗時保留編輯內容。
- 儲存、版本衝突、歷史還原與批次操作沿用既有 API 與權限。

## 驗證

- `node scripts/check-release.mjs`：前端 519、服務權限 89、移植 7 項，全數通過。
- 新增桌面非模態編輯、相鄰題切換草稿保存、目前題目標示及手機模態編輯測試。
- 使用本機唯讀預覽資料檢查 1440 px 桌面、390 px 手機、深色模式與各導覽切換；沒有對正式題庫寫入。
- 主站與投稿服務共用的四份 JS/CSS 資產已同步。
