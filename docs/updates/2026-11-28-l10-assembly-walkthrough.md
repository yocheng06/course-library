# 演算法 L10：裝配線逐步演示與題目排序

## 調整內容

- 讀取線上最新 L10 共 60 題，核對 11 題數值裝配線題，分成 4 組輸入。
- 裝配線解析提供上一步、下一步、重新開始、看完成結果。
- 每一步填完一站的兩個 f 值，列出留在原線、從另一線換入的公式及比較；未計算的格子顯示「—」。
- 末站與離場分開；最後才加離場成本並回溯一條最佳路徑。平手保留原線，末站平手顯示由線 1 離場的路徑。
- 顯示本題問站點、出廠、另一線結果或路徑的提示；不把出廠總時間誤用在中間站問題。
- 原有選項判讀及填格說明保留，長篇完整文字計算預設收起。原題、選項、答案、ID、題圖及資料庫版本不變。
- 沒有完整資料、額外限制、其他輸入格式或含題圖的版本不套用推算演示，保留原文字解析。

## 排序規則

先按主題，同一個已確認輸入的題組相鄰；組內單選、多選、填空。同類題組以最早題型排序。

裝配線的四組不同加工、進入、轉換及離場時間分開，不因標題相同併組。既有 LCS 表格題的相同輸入也相鄰；矩陣額外括號化限制保留，不忽略條件。檢查結果與完整順序見 `content/algorithms-l10-walkthrough-audit-20261128.json`。
