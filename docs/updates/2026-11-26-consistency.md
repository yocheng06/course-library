# 資料一致性與操作回饋（2026-11-26）

## 使用者行為

- 新投稿收據包含實際公開題目的 ID（略過重複題後仍正確），成功後提供「查看這題」與「繼續匯入」。單題投稿及分組匯入都會讀取公開 API 確認本次題目可供查題；確認失敗只重試讀取，不重送投稿。
- 閱讀與批次查題採用相同的公開快照檢查規則、共用快取鍵與跨分頁失效通知。投稿、管理修改或閱讀頁修改會通知同一瀏覽器的其他頁面；切回頁面也會重新確認。寫入途中尚未回傳的舊請求會被捨棄，保留有效快照並重試。正常閱讀同步不彈提示；失敗時保留可用資料及重試入口。
- 管理頁保留已上線的版本衝突比較、草稿下載與載入最新版本功能；伺服器仍以修訂號做原子寫入保護。
- 閱讀設定說明待複習、練習及測驗保存於目前瀏覽器，旁邊提供原有完整學習備份入口。投稿頁說明草稿與收據須另行下載；Cloudflare／網站登入不代表個人學習紀錄會跨裝置同步。

## 測試整理

原先 29 個列管失敗中，23 個過期案例已修正或改以目前介面驗證。調整包括新增單元後的索引、以實際快照計算題數、以真正的新單元測試動態章節、補齊抽取 renderer 的依賴、依畫面打亂後的選項位置作答，以及排序時允許分類名稱正規化但仍逐題保護題幹、選項、答案與其他內容。

沒有修改原題答案來讓測試通過。仍有六個內容回歸失敗，對應以下三道題，具體原因保存在 `tests/known-failures.json`：

| 題號 | 已確認的差異 | 處理 |

| `os6-065` | 原答案「任務必須在截止期限前完成」與選項「任務必須在截止時間內完成」用字不同，無可安全解析的選項鍵；雙語案例也受影響 | 查題保留待核對；原稿核准後再建立明確答案對照 |

## 正式備份與獨立還原

本次使用官方 Wrangler 將正式 D1 匯出 SQL，在獨立 SQLite 記憶體資料庫還原，檢查 integrity、題目 JSON、歷史對應及所有資料庫題圖 SHA-256；再與正式資料逐表指紋比較一致：

- 1,001 筆公開／已移除題目資料、149 筆投稿。
- 541 筆題目歷史、215 筆內建題修訂。
- 31 張資料庫題圖、單元設定與設定歷史。

匯出 SQL 含私人資料與帳號狀態，只保留於本機暫存，不提交 GitHub，也不放入公開檢查產物。這次完整 SQL 演練不會寫入正式資料庫。離線檢查命令：

```sh
node scripts/verify-d1-backup.mjs /安全位置/backup.sql /安全位置/report.json
```

另建立 `course-library-restore-check`，透過 `BACKUP_VERIFY_DB` 綁定，僅用於每週還原驗證。驗證器先檢查 `_restore_sandbox` 專用標記，再將一次 D1 batch 讀取的題目、投稿、歷史、內建修訂、單元與圖片還原到此測試庫，逐表比對並校驗每張圖；不複製管理者帳密或訪客紀錄。只有測試庫內的表會重建，正式 `DB` 只被讀取。

正式排程保留原清理排程，另外於每週一台北時間 04:30（UTC 星期日 20:30）執行驗證。測試庫保存最近 90 天的驗證結果；管理工具「版本、同步與備份」顯示最近一次狀態。測試庫是演練用途，不能取代另行保存的完整離線備份。GitHub 每週也會以隔離測試資料驗證還原程式，無需取得正式資料或憑證。
