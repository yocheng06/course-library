# 匯入流程簡化（待發布）

- 批次查題：空白文字區選檔後自動讀取並查題，等待當前科目題庫同步；同步期間改字或改範圍不會套用舊查詢。已有文字時保留加入／取代確認。
- 缺圖才顯示圖片資料夾入口；結果區亦可直接補圖。保留本次選檔於記憶體，補圖自動重試；取代本次匯入內容而非重複附加。重新整理後需重新選檔。
- 投稿：兩份 HTML 選齊自動配對，成功後才顯示科目與單元確認。未提供分類的 JSON 請使用者確認再讀取，避免默認分錯單元。單一範圍的預覽可修改資料並套用，會取消先前送出確認。
- 手動投稿草稿、答案、原文、歷史、分批重試規則維持。切換方式會還原手動草稿的科目與單元。
- 按鈕：公開這 N 題（只計未完成批次）、補答案並分享未收錄題目。
- 讀取與產生預覽均不會自動公開；仍需勾選確認並按公開按鈕。

驗證：91 項相關前端測試、服務建置及 64 項服務測試通過。未做瀏覽器畫面及手機實機驗證；未提交、推送或部署。
