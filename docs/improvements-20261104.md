# 2026-11-04：測驗、備份與發布檢查改進

本版已完成本機驗證；正式站版本可由管理狀態面板及 GitHub Actions 部署紀錄核對。測驗結果單獨下載／列印不在此版範圍。

## 測驗語言與可調比例

單元測驗提供全部、中文題（含雙語）、純英文題、自訂比例。自訂時填寫中文 0–100 的整數百分比，英文自動取剩餘比例，預設 90／10；例如 20 題、中文 70% 會抽中文 14 題、英文 6 題。中文題數依四捨五入計算，英文取剩餘題數；某語言題數不足時停用開始並提示調整，不以另一語言補足。

分類只檢查題幹與翻譯，不因中文題的英文選項、術語或答案將它歸成英文。搜尋、題目原文與老師答案保留。測驗紀錄的標題保存當場語言／比例。

## 手機閱讀

600px 以下把主題、題型、答案顯示與更多篩選放進預設收起的「篩選條件」，顯示已啟用條件數。搜尋與學習模式持續可用，桌面預設展開；篩選與語言隱藏可從摘要標籤取消。測驗詳細規則亦可收起。

## 個人完整學習備份 v2

沿用閱讀設定中的完整學習備份，新增每科最近一次已交卷測驗及未交卷暫存，包含當時題目、選項順序與測驗作答。仍支援 v1 備份；v1 不覆蓋測驗紀錄。

匯入先驗證所有內容，再寫入待複習、練習及測驗儲存區；其中一區寫入失敗會回復原值。已交卷結果依時間保留較新紀錄；暫存依更新時間合併。匯入的待複習視為既有標記，不能被錯題勾選的取消功能誤刪。上限 12 MB，不含圖片二進位或跨裝置自動同步。

## 管理備份與復原檢查

管理工具中的「完整備份與檢查」開啟新面板；可下載 JSON 封裝，含題目、投稿、修改歷史、內建覆寫、單元設定，以及這些資料引用的實際題圖，圖片以 base64 與 SHA-256 保存。重複圖片參照只下載一次。讀取僅允許本站圖片 API 與既有 GitHub 課程圖片路徑；資料夾外檔案與任意外部網址不會被抓取。

- 整包上限 128 MB，單張圖上限 12 MB。
- 任一圖片讀取失敗，下載檔標示「尚有缺漏」，不記為完整成功。
- 可離線檢查 JSON 結構、題庫校驗、圖片內容、缺圖與重複 ID，列出建議復原順序。
- 「檢查備份與復原準備」只做檢查，**不自動覆寫正式 D1／R2**；真正搬站先在獨立測試環境還原及測試，再決定正式切換。
- 不包含管理密碼、設定碼、API 金鑰或使用者私人學習資料。
- 面板的最近備份時間是此瀏覽器建立下載的紀錄，不宣稱作業系統確實寫檔完畢。

## 管理狀態面板

「版本與同步狀態」顯示主站版本、API 版本與建置指紋、檢查時間、兩科隨附快照時間、後端題庫資料版本，以及本瀏覽器最近建立／驗證備份時間。兩端版本不同或其中一端無法取得時明確提示。

`GET /api/manage/system` 僅管理者可讀，不暴露金鑰與帳密。不同網域不能直接讀取主站 localStorage，因此主站個人快取的同步狀態仍在主站查看；快照時間也不冒充最新投稿時間。

## 自動檢查與 Pages 門檻

```sh
npm ci
npm --prefix contribution-service ci
npm run verify:release
```

`verify:release` 跑全部前端測試、Worker 建置及後端權限測試，完整輸出放在 `artifacts/checks/`。`tests/known-failures.json` 逐項列出本次改動前就存在的舊差異，附原因；這些不會被報成通過。任何未列管的新失敗、測試崩潰／逾時、不完整 TAP、後端建置或測試失敗都回傳非零。

原基線 381 項前端測試有 45 個失敗；修正 linkedom fixture 跨頁狀態殘留、同步共用來源後，列管剩餘的 27 個舊差異。新功能測試另外加入，總數會隨程式改變，CI 摘要列出真實數字。已知舊差異需繼續逐項處理，不能把這份清單當成永久豁免；移除任何已修好的條目後，可防止同類回歸被放過。

`.github/workflows/check-and-publish.yml`：PR 執行檢查；main 檢查成功才建立靜態產物並呼叫 Pages 部署。靜態產物只含根目錄 HTML、assets 及 README，不發布後端來源、測試輸出與私人備份。Worker 仍經原 Sites 流程獨立發布。

**正式啟用時的必要步驟：** 在 GitHub Repository → Settings → Pages 把來源切換成 GitHub Actions，才能讓新工作流程成為主站發布門檻。若維持舊的分支式 Pages 發布，GitHub 仍可能先跑舊發布流程；只新增 YAML 不代表舊流程已被停用。2026-11-04 發布時已將來源切換為 GitHub Actions；主站需通過此工作流程檢查才部署。

## 驗證與限制

已驗證可調語言比例、數量不足、原文保留、備份匯入回復、缺圖與資料破損、管理 API 權限、手機篩選收合，以及新失敗阻擋邏輯。本機瀏覽器已確認 70%／30% 顯示 14／6 題；沒有為測試寫入公開題庫或操作正式備份。

完整備份封裝用模擬圖片與資料驗證；正式 R2 的所有歷史圖片可否下載，需要登入後實際建立備份才能確認。手機各瀏覽器及超大型備份的記憶體負擔仍需持續實機觀察。
