# 單元新增與拖拉排序（已核准發布）

- 管理單元新增「＋ 新增單元」：編號 1–99 與名稱必填，先加入本機清單，再一起儲存。既有編號不能重複，也不能藉由新增改掉既有單元 ID。
- 每列提供拖曳把手，使用 Pointer Events 支援滑鼠、觸控與觸控筆。拖拉時即時換位，靠近畫面上下緣可捲動；放開才更新草稿順序，儲存後才公開套用。
- Esc、pointercancel 或遺失指標擷取會恢復本次拖拉前的順序。已修改的名稱與新增草稿保留。
- 保留上移／下移；拖曳把手亦可使用鍵盤上下方向鍵排序。手機只在把手上停用原生捲動，其他區域仍可正常捲動。
- 顯示 L2、L3 等單元編號，不將 basics、architecture 等內部 ID 當作主要辨識文字。原始 ID 不變。
- 後端允許站主新增空白單元，保留全部既有單元、版本衝突保護與修改歷史；新單元在公開單元中繼資料中可供投稿與查題選擇，不必先投稿一題。
- 45 項相關前端測試及 67 項服務測試通過。已在本機測試畫面實際把第三個單元拖到第一個，並檢查新增單元及窄版排版；觸控使用事件測試，未做實體手機測試。
- 本次已獲使用者核准發布，同時包含「匯入這 N 題」文案修改。正式題庫沒有被新增、移動或刪除。
