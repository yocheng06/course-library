# 題庫管理改善（已核准發布）

## 清單與批次操作
- 全部題目、最近修改、已移除共用勾選與篩選。已移除只顯示還原，公開題只顯示移除；混合選取分別顯示可操作題數。
- 「勾選已載入題目」僅涵蓋目前已顯示清單；「勾選全部符合條件的題目」逐頁取得符合篩選的題目，完成前不會改動原選取。
- 批次動作逐題核對最新 revision；成功項目不重送，失敗項目保留勾選，可只重試未完成題目。
- 移除完成提供「復原剛才移除的題目」；使用同一版本檢查，遇到後續修改會保留原狀並提示。
- 科目、單元、來源、排序、搜尋文字，以及目前管理頁籤依管理者保存在本機。

## 歷史與版本比較
- 歷史以修改前後並排呈現，只列出異動欄位，並標記實際不同的文字；保留上一版及原始版還原。
- 題庫健檢的疑似重複比較新增保留一邊、移除另一邊入口；必須選擇對照版本，再開啟指定題目的移除確認。不會依題幹相同自動刪題。

## 單元管理
- 新增獨立「管理單元」頁籤，可修改名稱、上移／下移排序。
- 設定與題目 ID、答案及題目版本分離。新設定有 revision 競爭保護及修改前後備份紀錄。
- 公開 /api/units、/api/questions 帶入單元設定；閱讀、批次查題與投稿選單同步後套用，快取也保留名稱與順序。
- 投稿題目的編輯器可更改所屬單元，沿用既有版本歷史。內建題目仍保留來源單元，這次沒有開放內建題目的跨單元搬移。
- 資料表：unit_settings、unit_settings_history；含 0007 遷移及相容舊部署的首次讀取建表。

## 驗證與限制
- 71 項相關前端測試通過，涵蓋跨頁全選、移除後復原、失敗重試、篩選保留、歷史差異與文字跳脫、單元設定及兩科閱讀題目 ID 不變。
- 66 項服務測試通過，涵蓋管理權限、單元設定版本衝突、公開中繼資料同步、備份、原題不被重寫，以及投稿題目移動與歷史保留。
- 服務建置通過。沒有對正式站題目進行移除、移動或改名；本次已獲使用者核准發布。
- Work 設定停用瀏覽器，因此尚未做實際畫面及手機操作驗證。
