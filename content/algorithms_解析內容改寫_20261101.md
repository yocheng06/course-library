## L2-003｜L2

下列漸進符號集合的數學定義，哪些是正確的？

「Ω(g(n)) 包含所有滿足 0 <= c*g(n) <= f(n) 的函數 f(n) (當 n >= n0)」 用上下兩個常數倍夾住 f；「o(g(n)) 的極限關係為 lim f(n)/g(n) = 0」 給下界；「Θ(g(n)) 包含所有滿足 c1*g(n) <= f(n) <= c2*g(n) 的函數 f(n) (當 n >= n0)」 給上界，其中 c、c₁、c₂ 都必須是正的常數，n₀ 是門檻。「O(g(n)) 包含所有滿足 0 <= f(n) <= c*g(n) 的函數 f(n) (當 n >= n0)」 在 g 最終為正時以 f/g→0 表示 f=o(g)。這些是對足夠大的 n 的關係，不要求從 n=1 就成立。

## L2-010｜L2

下列關於漸進符號對稱性（Symmetry）與轉置對稱性（Transpose Symmetry）的敘述，哪些正確？

Θ 的兩側常數倍界可反過來寫，所以 f＝Θ(g) 等價於 g＝Θ(f)。上界反轉後是下界，因此 f＝O(g) 等價於 g＝Ω(f)；嚴格相對較小的小 o，反轉後對應嚴格較大的小 ω。

O 本身不對稱：n＝O(n²)，但 n² 並不是 O(n)，因為 n²/n＝n 不受固定常數限制。可用這個例子排除「O 交換兩邊仍是 O」的敘述。

## L2-013｜L2

若 m <= n 則 f(m) <= f(n)，此函數屬於哪一種單調性？

m≤n 時有 f(m)≤f(n)，表示輸入增加時函數值不會下降，是單調不遞減；本題選 Monotonically increasing。例：[1,1,3,5] 允許連續相等，仍符合非嚴格單調。Strictly increasing 要求 m<n 時 f(m)<f(n)，會排除持平段，因此比題幹條件更強。

## L2-016｜L2

對於任意實數 x 或整數 n，下列關於地板與天花板函數的數學性質哪些是正確的？（D 選項中的 a、b 為正整數。）

n 為偶數或奇數時，⌈n/2⌉ 與 ⌊n/2⌋ 相加都等於 n。「x - 1 < ⌊x⌋ <= x」、「x <= ⌈x⌉ < x + 1」 分別是地板與天花板函數的定義。「⌊⌊n/a⌋/b⌋ = ⌊n/(ab)⌋」：當 n 為整數且 a、b 為正整數時，先把 n 除以 a 再向下取整，接著除以 b 再向下取整，結果等於直接把 n 除以 ab 後向下取整。

## L2-017｜L2

關於模運算（Modular arithmetic），下列哪些數學公式或關係是正確的？

以正整數 n 為模數，令 q=⌊a/n⌋，則餘數 r=a-qn 滿足 0≤r<n，得到 「a mod n = a - ⌊a/n⌋ * n」。若 a、b 的餘數相同，則 a-b 是 n 的整數倍，寫成 a≡b (mod n)，所以 「若 (a mod n) = (b mod n)，則寫作 a ≡ b (mod n)」、「a mod n 代表 a 除以 n 的餘數」、「若 a ≡ b (mod n)，表示 a 與 b 模 n 等價」 也成立。例：-1 mod 5=4；程式語言的 % 對負數可能採不同規則。

## L2-020｜L2

對於任何常數 a > 1，當 n 趨近於無窮大時，(n^b / a^n) 的極限值為多少？

把比值取自然對數：ln(nᵇ/aⁿ)=b ln n−n ln a。因 a>1，所以 ln a>0；固定 b 的 ln n 成長比 n 慢，差值趨於 −∞。再取指數可知 nᵇ/aⁿ→0，故選 「0(zero)」。b 必須是不隨 n 改變的常數。

## L2-019｜L2

關於函數增長率的比較，下列哪些敘述是正確的？

在正的固定指數、底數大於 1 的條件下，常見順序是 (log n)^k ≺ nᵇ ≺ aⁿ ≺ n!。「n log n 增長速度快於 n^2」 錯，因 (n log n)/n²=log n/n→0；「對數函數增長快於階乘函數」 也顛倒。「任何正多項式函數增長速度都快於任何多對數 (Polylogarithmic) 函數」、「任何正指數函數增長速度都快於任何多項式函數」 所描述的是 polylog 小於正次方多項式、常數底指數大於多項式。常數多項式 n⁰ 不屬於這裡「正次方」的比較。

## L2-024｜L2

下列哪些函數屬於多對數有界（Polylogarithmically bounded）的範疇？

多對數有界表示：存在固定常數 k，使函數最終不超過某個常數倍的 (log n)^k。lg² n 與 (lg n)⁵ 直接符合；lg(lg n) 在 n 足夠大時也小於 lg n，所以同樣有界。

n 本身比任何固定次方的 log n 都長得快，不屬多對數有界。例：n＝2²⁰ 時，n 約百萬，而 lg n＝20；題目看的是 n 持續增大後的趨勢，不是某個小 n 的數值比較。

## L2-025｜L2

對於所有 x > -1，下列關於對數函數（Logarithm）的數學不等式哪些是正確的？

對 x>−1，可比較面積或微分得到 x/(1+x)≤ln(1+x)≤x；x＝0 時兩邊都是 0，其餘允許範圍的 x 才有 ln(1+x)<x。因此題目若包含 x＝0，「嚴格小於 x」不能說對所有 x>−1 都成立。ln(1+x)>x 則與這個上界相反。

冪級數 ln(1+x)＝x−x²/2+x³/3−… 在題目另註的 |x|<1 範圍成立，不能直接套到所有 x>−1。老師指定答案保留，理解時要同時檢查「嚴格／非嚴格不等號」及「級數的收斂範圍」，不只背選項。

## L2-026｜L2

對於所有實數 x，下列關於指數函數的性質哪些是正確的？

eˣ≥1+x 對所有實數 x 成立，在 x＝0 取等號；固定 x 時，limₙ→∞(1+x/n)ⁿ＝eˣ 也成立。eˣ 並非永遠小於 1，例如 x＝1 時 e>1。

老師答案保留，但「|x|≤1 時 eˣ≤1+x+x²/2」照原式並不對所有該區間的 x 成立：取 x＝1，左邊約 2.718，右邊為 2.5，直接得到反例。當 0<x≤1，泰勒展開還有正的 x³/6 等項，不能用二次截斷式作這種上界。若要成立，需另補適當條件或餘項界；解析不把錯誤不等式當成通則。

## L2-028｜L2

重複對數函數值 lg* 16 的結果為多少？

lg* n 不是只取一次 log，而是反覆取 log₂，直到結果≤1 的次數。16→4→2→1，共做 3 次，所以選 「3」。停止值 1 不再取 log；若把 lg16=4 當成結果，便混淆了單次對數與重複對數。

## L2-027｜L2

關於重複對數函數（Iterative logarithm function, lg* n），下列敘述哪些是正確的？

以底數 2、降到 ≤1 為停止條件：65536→16→4→2→1，所以 「lg* 65536 = 4」 為 4 次；2→1，所以 「lg* 2 = 1」 為 1 次。能讓次數超過 5 的數字必須大到遠超一般可表示的資料規模，因此 「在可觀測宇宙中幾乎遇不到 n 使得 lg* n > 5」 是對實務規模的說明；每多一次迭代所需的輸入規模會以冪塔方式增加，「它是極度緩慢增長的函數」 因而成立。

## L2-032｜L2

關於費氏數列（Fibonacci numbers），下列定義與數學公式哪些是正確的？

「對 i>=2，Fi=F(i-1)+F(i-2)」 給出起始值與遞迴關係：0、1、1、2、3、5…。令 φ=(1+√5)/2、ψ=(1−√5)/2，則 Fᵢ=(φⁱ−ψⁱ)/√5；|ψ|<1，其冪次趨於 0，而 φ>1，因此 Fᵢ=Θ(φⁱ)，呈指數等級增長，「可用黃金比例 φ 與其共軛表示閉式公式」、「Fibonacci 數列呈指數等級增長」 成立。

## L2-047｜L2

關於 Insertion Sort 的 loop invariant，下列哪些敘述正確？

插入排序第 j 輪開始前，A[1..j−1] 已按大小排序，而且恰好包含原輸入前 j−1 個元素；這是迴圈不變量。初始 j＝2 時，只有一個元素的前綴天然有序。每輪把 A[j] 插進正確位置，使已排序前綴擴大一格。迴圈結束 j＝n+1 時，有序前綴就涵蓋整個陣列。

未處理的 A[j..n] 不保證有序。注意 A 是陣列名稱；不變量應依「已排序前綴」「原元素保持不變」「逐輪維持」的內容辨認，與選項排在哪個位置無關。

## L2-053｜L2

在合併排序法（Merge Sort）的合併步驟 Merge(A, p, q, r) 中，使用了哪些輔助常規？

此題指附哨兵的經典 Merge：先複製左右已排序區段到 L、R，尾端各放一個 ∞；每次比較兩端尚未取出的最小元素，把較小者寫回 「建立了兩個輔助陣列 L 和 R」。「在輔助陣列尾端放置無限大值（∞）作為哨兵（Sentinels）」、「將排序結果複製回原陣列 A」、「完全不需要額外的記憶體空間」 因此成立，「建立了兩個輔助陣列 L 和 R」 錯，因輔助陣列總空間是 Θ(n)。沒有哨兵的 Merge 版本也正確，只是必須另外檢查序列是否已取完。

## L2-058｜L2

關於 RAM（Random Access Machine）模型，下列哪些敘述正確？

本題採單處理器 word-RAM：記憶體可按位址直接存取，且對固定字長或適當 word-size 內資料的基本讀寫、算術指令視為 O(1)。「基本指令可視為常數時間」、「記憶體可隨機存取」、「基本模型以單一處理器、循序執行為主」 成立。不能把這個假設擴大成任意長整數運算都是常數時間；「假設記憶體或通訊頻寬是無限大」 的無限通訊頻寬也不是 RAM 模型的條件。

## L2-059｜L2

為什麼演算法分析通常特別關注 worst-case running time？

最壞情況提供每次執行都不會超過的時間界。「最壞情況在實務上可能相當常見」：某些常見輸入會觸發較差行為，例如 Insertion Sort 的反向排列。「平均情況有時和最壞情況一樣差，例如 insertion sort」：對均勻隨機排列的 Insertion Sort，平均與最壞時間都為 Θ(n²)，雖然常數不相同。「因為最壞情況一定最容易算出精確常數」 錯，最壞情況不保證最容易求精確常數；分析選它是為了上界保證。

## L3-035｜L3

大師定理 Case 3 的條件包含？

令 p＝log_b a。Case 3 要求存在固定 ε>0，使 f(n)＝Ω(n^(p+ε))，並滿足規則性條件：存在固定 c<1，使 a f(n/b)≤c f(n) 對足夠大的 n 成立。此時工作由根部主導，T(n)＝Θ(f(n))。

例如 2T(n/2)+n²，p＝1，n² 比 n 多一個正次方，且 2(n/2)²＝n²/2，所以可得 Θ(n²)。老師答案保留，但原選項的 O(n^(p−ε)) 型態屬 Case 1 的方向，不是 Case 3；不能把兩種條件背成一樣。原上標也疑似有排版問題，以上以完整公式說明。

## L3-036｜L3

大師定理 Case 1 的條件包含？

大師定理適用形式為 T(n)＝aT(n/b)+f(n)，其中 a≥1、b>1 為固定常數。先計算臨界函數 n^(log_b a)；Case 1 要求存在固定 ε>0，使 f(n)＝O(n^(log_b a−ε))，也就是 f(n) 比臨界函數至少慢一個多項式因子。結果為 Θ(n^(log_b a))。

例如 T(n)＝4T(n/2)+n，臨界函數 n²，n 比 n² 慢，可取 ε＝1，所以解為 Θ(n²)。「f(n) 成長較快」方向相反，不是 Case 1。原選項的上標排版容易誤讀，正確位置是把 ε 從指數 log_b a 中扣除，不是乘上 (a−ε)。

## L4-056｜L4

堆積的完整樹形狀意味著？

完全二元樹的各層由上往下填，最後一層由左往右填。因而不能在同一層先留空位、再放右邊節點，但最後一層不必全部填滿。

「除最後一層外均填滿」、「沒有空缺」 描述這種緊密排列；「可以有空節點」 所允許的中間空節點會破壞完全二元樹形狀。

## L4-050｜L4

關於 Binary Heap 陣列表示法，下列何者正確？

索引從 1 開始時，A[1] 是根，i 的父節點為 floor(i/2)，左右子節點為 2i、2i+1，故選 「父節點位於 ⌊ i/2 ⌋」、「子節點位於 2i 與 2i+1」、「索引 1 為根節點」。

陣列長度表示可存放的範圍，heap-size 表示目前仍屬於堆積的有效範圍。Heapsort 已排序的尾端仍在陣列內，卻不再屬於堆積，所以兩者不一定相等。

## L4-059｜L4

Max-Heapify 需要哪些參數？

標準 MAX-HEAPIFY(A,i) 的輸入是陣列 A 與待修復節點索引 i。函式假設 i 的左右子樹已是 Max-Heap，只需把 A[i] 往較大的子節點方向調整。

例如 A[i]＝4，左右子節點是 9、7，先與 9 交換，再從 4 新的位置繼續修復。有效堆積大小可由 heap-size[A] 等狀態取得，不一定要把整個 n 另當參數；程式也不需要額外傳入「某個比較結果」。A 在此是陣列變數，不是正確選項代號。

## L4-043｜L4

Max-Heapify 可能會影響哪些節點的屬性？

Max-Heapify 先比較目標節點與左右子節點，必要時把較大的子節點換上來，再沿被換下去的那一側遞迴修復。因而 「右子節點」、「左子節點」、「目標節點」 都可能參與調整，修復也可能繼續深入更下層。

此操作只處理以 i 為根的子樹，不會向上修復 i 的父節點；向上調整是 Increase-Key 等操作的工作。

## L4-047｜L4

關於虛擬碼的 第6與第10行 請問以下哪些正確

核心觀念：largest 記錄目前在根、左子節點與右子節點中找到的最大值位置。

解題步驟：第 6 行必須比較 A[r] > A[largest]，才能把更大的右子節點列為候選，故選 「line 6：A[r] > A[largest]」。交換 A[i] 與 A[largest] 後，可能違規的值已移到 largest，必須在該位置呼叫 Max-Heapify(A, largest)，故選 「line 10：Max-Heapify(A, largest)」。

適用條件：左右子樹原先已是堆積。比較符號反向或仍在 i 遞迴，都不能完成被換下去位置的修復。

## L4-045｜L4

下列哪些關於堆積排序的敘述是正確的？

Heapsort 在原陣列中交換，無須 O(n) 的第二個排序陣列；建堆積後逐一取出最大值，平均與最壞時間為 O(n log n)。

它的遠距離交換可能讓相同鍵值的元素改變相對順序，因此不穩定。「原地排序」、「複雜度 O(n log n)」、「不穩定排序」 分別對應這三項性質，「需要 O(n) 額外空間」 不是標準原地實作的必要空間。

## L4-053｜L4

下列哪些是堆積排序的特性？

標準教材版本以遞迴 Max-Heapify 向下修復堆積，並在原陣列中交換；整體時間上界為 O(n log n)，所以 「複雜度 O(n log n)」、「使用遞迴」、「原地排序」 符合此版本。

遠距離交換不保證相同鍵值維持原順序，因此不是穩定排序。Heapify 也可改寫成迭代版本；「使用遞迴」描述的是這份虛擬碼的實作方式。

## L4-052｜L4

Increase-Key 動作需要？

Increase-Key 先確認新鍵值不小於舊值，再更新指定節點。若它大於父節點就交換並繼續向上，直到根或父節點已不小於它。因此需更新值、維持堆積規則並向上比較，選 「維護堆積屬性」、「更新節點值」、「向上比較直到根」。

「直到根」是最長可能路徑，不代表每次都必須到根；操作可從任意合法索引開始，並不限根節點。

## L5-036｜L5

關於快速排序的遞迴，下列何者正確？

得到 pivot 位置 q 後，左右兩段尚未完全排序，應分別遞迴 QUICKSORT(「只對右子陣列遞迴」,p,q−1) 及 QUICKSORT(「只對右子陣列遞迴」,q+1,r)。

## L5-005｜L5

快速排序的遞迴呼叫順序為何？

課本 QUICKSORT 先透過 PARTITION 得到 q，接著 QUICKSORT(「先對 p 到 q-1 進行排序」,p,q−1)，再 QUICKSORT(「先對 p 到 q-1 進行排序」,q+1,r)。pivot 已就位，無須對 pivot 本身再排序。

## L5-007｜L5

選出課本上的 Quicksort Partition(A, p, r) average-case partition 可能的 遞迴式子

課本 Partition 一次處理目前範圍全部元素，因此非遞迴成本為 Θ(n)。若 pivot 每次都是最小或最大，且子問題規模為 0 與 n−1，得到 T(n)＝T(n−1)+Θ(n)。展開為 n+(n−1)+…+1＝n(n+1)/2，所以最壞時間 Θ(n²)。

不要把平衡分割的 2T(n/2)+Θ(n) 套進此題；題目指定的是極端不平衡的分割。

## L5-054｜L5

若要達成 O(n log n) 的期望時間複雜度，快速排序需要？

系統選 「正確的遞迴處理」、「隨機選擇 pivot」、「均勻的分割」。隨機化 pivot 會帶來期望 O(nlogn)，遞迴必須正確；均勻分割能讓遞迴樹較淺，但理論上不需「每一層都均勻」才能達成此期望。

## L5-053｜L5

快速排序的「原地 (in-place)」特性指？

原地排序指主要操作直接在輸入陣列上進行，不需額外複製一份陣列。Partition 本身可用常數個暫存變數完成；但完整遞迴版 QuickSort 若計入呼叫堆疊，通常仍需 O(logn) 額外空間（最差 O(n)）。本題依題庫答案選 「不需要複製陣列」、「在輸入陣列本身進行運算」、「僅使用常數額外空間」。

## L6-059｜L6

基數排序(Radix Sort)在處理 b-bit 數字時，時間複雜度為？

每輪以穩定計數排序處理 r 個位元，鍵值範圍為 2^r，每輪時間 Θ(n+2^r)。共需 ⌈b/r⌉ 輪，所以一般形式為 Θ(⌈b/r⌉(n+2^r))；在課本 1≤r≤b 的設定下，與選項 「Θ((b/r)(n + 2^r))」 的 Θ((b/r)(n+2^r)) 同階。

## L6-049｜L6

下列哪些特徵是基數排序與計數排序(Radix Sort and Counting Sort)共有的？

C 正確。計數排序與基數排序都利用鍵值結構，並非只靠鍵值兩兩比較來決定次序。計數排序在 k=O(n) 時為 Θ(n)；基數排序還需位數／輪數與每輪鍵值範圍等條件受控。「皆需穩定排序子程序」 不對：基數排序會呼叫穩定子排序，計數排序本身則不必再呼叫另一個穩定排序子程序。

## L6-050｜L6

基數排序(Radix Sort)的優點有？

依提供題庫答案選 「可擴展性強」、「靈活處理多維資料」、「穩定」、「時間複雜度隨輸入長度線性增加」。基數排序可將鍵值拆為位數或多個欄位，按低優先序欄位到高優先序欄位依序做穩定排序，因此能處理多欄位鍵值。「穩定」 的穩定性以每輪子排序穩定為前提；「時間複雜度隨輸入長度線性增加」 的線性成長需位數與每輪基數等參數固定或受控，並非任意長度鍵值都保證 Θ(n)。

## L6-018｜L6

桶排序(Bucket Sort)適合處理？

此題官方答案是 「需要線性效能數據」、「均勻分佈數據」、「區間範圍明確數據」：在資料大致均勻分布、值域區間容易劃分時，桶排序能取得理想的期望線性效能，因而適合有線性效率需求的情境。注意「需要線性效能」本身不是保證 O(n) 的充分條件，仍需分布假設。

## L6-061｜L6

下列哪種排序演算法是「穩定」的（Stable）？

提供的測驗答案為單選 「計數排序」。標準計數排序依輸入由後往前回填，可維持同鍵值元素的相對順序。桶排序若分桶時保序、桶內採穩定排序，也可以穩定；快速排序與堆積排序的標準版本通常不穩定。

## L6-006｜L6

線性時間排序演算法的共通限制包括？

「空間消耗可能較大」、「通常有特定的輸入假設」 正確。這些排序利用值域、位數或資料分布等額外資訊，突破「僅以元素兩兩比較決定次序」模型的 Ω(n log n) 下界，通常也需要額外陣列或桶。「不使用比較模型」 並不表示程式中完全沒有比較：桶內仍可使用插入排序。負數也能透過位移或適當編碼處理，因此 「無法處理負數」 不是共通限制。

## L6-029｜L6

下列關於排序演算法複雜度的敘述，正確的有？

計數排序的時間複雜度為 Θ(n+k)，其中 k 是值域大小。對 n 個互異元素進行比較排序，最壞情況的比較次數下界為 Ω(n log n)。桶排序在資料獨立且均勻分布、桶數與 n 同階等標準假設下，期望時間為 Θ(n)；缺少這些條件時不能保證線性效能。因此 「計數排序可以做到 Θ(n+k)」、「比較排序下界 Ω(n log n)」、「桶排序平均情況為 Θ(n)」 正確，「所有排序都能做到 O(n)」「所有排序都能做到 O(n)」不成立。

## L6-014｜L6

計數排序(Counting Sort)中，陣列 C 的作用是？

核心觀念：
把 C 想成每種數字的登記表。例：A＝[2,0,2,1]，數完得到 C[0..2]＝[1,1,2]，表示 0 有 1 個、1 有 1 個、2 有 2 個。累加後變成 [1,2,4]，表示小於等於 0、1、2 的數分別有 1、2、4 個。回填時 C 又會隨使用而遞減，所以一定先看演算法做到哪個階段。

選項判讀：
儲存指標：不選。C 的每格存整數計數／位置界線，不是記憶體指標。
儲存每個鍵的出現次數或累積計數：選這項。符合這一階段 C 所記錄的計數資訊。
儲存原始資料：不選。原始資料在 A；C 不會把 A 的全部元素依原順序再存一遍。
作為樞紐：不選。樞紐是快速排序等方法的角色，計數排序沒有挑 pivot。

本題答案：儲存每個鍵的出現次數或累積計數。

## L6-062｜L6

計數排序中的 C[i] 儲存的是？

這題依教材「累積完成、尚未回填」的時點判讀：C[i] 是原輸入中鍵值小於等於 i 的元素總數。例：A＝[2,0,2,1]，先數次數得到 C[0..2]＝[1,1,2]；累積後為 [1,2,4]，所以 C[1]＝2，因為 0 與 1 共兩個元素小於等於 1。

它是整數計數，不是記憶體指標，也不是把鍵值 i 本身存進 C[i]。「元素 i 的位置」太籠統：累積總數雖可用作值 i 的回填右界，但不是每個同值元素都在同一個位置。

題目沒有明寫階段，需特別區分：累積前是恰好等於 i 的次數；回填時 C[i] 會逐次遞減；全部回填後，標準版本的 C[i] 變成原輸入嚴格小於 i 的個數，不能在每個時點都套用同一解釋。

## L6-017｜L6

計數排序(Counting Sort)的空間複雜度主要取決於？

核心觀念：
先看題目在強調哪一塊空間。計數表 C 要替 0～k 每種數字留一格，所以有 k＋1 格，為 Θ(k)；範圍越大，C 越大。輸出 B 另外需要 n 格。因此本題答案強調計數表取決於 k；若問整個穩定版本的輔助空間，必須回答 Θ(n＋k)，不能說 n 完全不影響。

選項判讀：
遞迴深度：不選。這個版本沒有遞迴呼叫或樹結構，空間不由這些量決定。
樹的高度：不選。這個版本沒有遞迴呼叫或樹結構，空間不由這些量決定。
輸入長度 n：不選。n 確實影響輸出 B 的大小，但本題單選著重的是計數表 C 的範圍 k；若問總空間就要同時算 n＋k。
參數 k (數值範圍)：選這項。C 必須涵蓋整個鍵值範圍，所以大小直接隨 k 增加。

本題答案：「參數 k (數值範圍)」。

## L6-026｜L6

如果所有輸入元素皆為 1 到 k，計數排序(Counting Sort)的時間複雜度為？

核心觀念：
把四段工作分開算：初始化 C 要 k 格 → Θ(k)；掃描 A 計數要 n 次 → Θ(n)；累積 C 要 k 次 → Θ(k)；由右往左回填 B 要 n 次 → Θ(n)。加起來 Θ(k＋n＋k＋n)＝Θ(n＋k)。迴圈是一段接一段，不能把 n 和 k 相乘。

選項判讀：
Θ(n + k)：選這項。同時計入掃描 n 筆資料與處理 k 種鍵值的成本。
Θ(k log k)：不選。這個流程沒有比較排序的對數分割；仍須掃描 n 筆資料，不能只有 log n，也不需要乘上 log n。
Θ(n log n)：不選。這個流程沒有比較排序的對數分割；仍須掃描 n 筆資料，不能只有 log n，也不需要乘上 log n。
Θ(n^2)：不選。沒有對所有輸入做雙層兩兩比較；這裡把先後執行的成本相加。

本題答案：Θ(n + k)。

## L6-040｜L6

計數排序（Counting Sort）要求輸入元素必須是？

核心觀念：
課本基本版本直接用鍵值存取 C[x]，因此 x 要是已知有限範圍的整數索引。例如數字 3 放到 C[3]；任意實數 3.7 不能直接當陣列下標。更一般的資料可以先取出／轉換整數鍵值，但那是額外的前處理，不是直接把任何物件都交給基本版本。

選項判讀：
字串：不選。這不是基本版本可直接拿來存取 C[x] 的有界整數鍵。
結構體：不選。這不是基本版本可直接拿來存取 C[x] 的有界整數鍵。
整數：選這項。有界整數可以直接對應計數表下標，符合基本版本的要求。
實數：不選。任意實數不能直接作為離散陣列下標；須先有額外的轉換與範圍條件。

本題答案：整數。

## L6-054｜L6

當 k = O(n) 時，計數排序(Counting Sort)的時間複雜度為？

核心觀念：
先寫出一般式 Θ(n＋k)。k＝O(n) 表示存在固定常數 c，使得 k 不超過 c×n。於是 n＋k 不超過 (1＋c)n；另一方面掃描全部輸入至少要 n 次，所以總時間同時有線性上界與線性下界，得到 Θ(n)。不是看到兩個迴圈就相乘成 n²。

選項判讀：
Θ(n^2)：不選。沒有對所有輸入做雙層兩兩比較；這裡把先後執行的成本相加。
Θ(n log n)：不選。這個流程沒有比較排序的對數分割；仍須掃描 n 筆資料，不能只有 log n，也不需要乘上 log n。
Θ(n)：選這項。與上方成本推導相符：k＝O(n) 後，Θ(n＋k) 簡化為 Θ(n)。
Θ(log n)：不選。這個流程沒有比較排序的對數分割；仍須掃描 n 筆資料，不能只有 log n，也不需要乘上 log n。

本題答案：Θ(n)。

## L6-009｜L6

計數排序(Counting Sort)需要哪幾個輔助陣列？

課本計數排序的三個角色不同：「A (輸入陣列)」 是原始輸入陣列；「D (用於遞迴)」 是另外建立的排序結果陣列；C 是另外建立的計數／累積位置表。所以題目問「額外需要的陣列」時，應辨認「用於存放結果」與「用於計數」這兩個內容。「A (輸入陣列)」 原本就存在，不能再算一次額外建立；課本版本以迴圈計數與回填，沒有為遞迴另外建立陣列 D。若輸入 n 個數、鍵範圍為 0..k，「D (用於遞迴)」 需要 n 格，C 需要 k+1 格，總輔助空間 Θ(n+k)。此處 「A (輸入陣列)」、「D (用於遞迴)」、C 是演算法的陣列名稱，與練習畫面上的選項代號無關。

## L6-031｜L6

哪些情況下不適合使用計數排序(Counting Sort)？

計數排序的時間一般為 Θ(n+k)，標準穩定版本另需 n 格輸出陣列與 k+1 格計數表。

「鍵值範圍 k 極大」會使時間與空間都花在大量沒出現的鍵上。例如只有 3 筆資料，k 卻是 10 億，初始化與累積仍可能要處理約 10 億格，因此不合適。「記憶體非常有限」也難容納計數表與輸出陣列。

「鍵值為浮點數」不能直接當成標準計數表的離散整數索引，除非另有可行的離散化與範圍限制。「資料僅為整數」本身不是缺點，有界整數正是此方法的典型適用條件；還需同時看鍵值範圍是否受控。

## L6-064｜L6

計數排序(Counting Sort)的特性包含？

核心觀念：
特性要連同條件一起看：時間一般是 Θ(n＋k)，只有 k＝O(n) 才能說對 n 是線性；C 本身占 Θ(k)，加上 B 才是 Θ(n＋k)；標準「由右往左讀 A、先放入 B 再遞減 C」的版本是穩定排序。例：A 中兩個 2 分別標為 2甲、2乙，乙先被放到較右邊，甲後來放到左邊，結果仍是甲在乙前。

選項判讀：
線性時間複雜度：選這項。要加上 k＝O(n) 的條件；一般式是 Θ(n＋k)。
需要 O(k) 額外空間：選這項。這描述計數表 C 的額外空間；計入輸出 B 的總輔助空間仍是 Θ(n＋k)。
穩定：選這項。由右往左處理相同鍵值，先把後出現者放到右側，保留原本的相對順序。
適用於實數：不選。任意實數不能直接作為離散陣列下標；須先有額外的轉換與範圍條件。

本題答案：「線性時間複雜度」、「需要 O(k) 額外空間」、「穩定」。

## L7-2468｜L7

一個集合的第 i 個順序統計量（ith order statistic）是指該集合中第幾個小的元素？

本題答案：「第 i 小的元素」

解題思路與過程
把數字由小到大排列後，第 i 個就是第 i 小。這裡的「第幾個」指大小排名，不是原陣列的位置。
例如原資料 [9,2,7,4]，排序後是 [2,4,7,9]。i＝3 的答案是 7；原陣列第 3 格剛好也是 7 只是巧合，換個排列仍要得到同一答案。

逐一看選項
第 i 小的元素
「第 i 小的元素」 是定義本身：排序後數第 i 個。

第 i 大的元素
第 i 大由大往小數；本例第 3 大是 4，與第 3 小不同。

中位數
中位數只對應中間順位，不能代表任意 i。

平均數
平均數要將數字加總再除以個數，甚至不一定是集合中的元素。

## L7-2471｜L7

選擇問題（Selection Problem）的輸入為何？

本題答案：「一組包含 n 個數字的集合與數字 i」

解題思路與過程
想像有人說「幫我找第 3 小」，你需要兩樣資訊：有哪些數字，以及要第幾小。
例：輸入 A＝[9,2,7,4]、i＝3，輸出 7。n＝4 可由資料長度取得；合法順位必須滿足 1≤i≤n。

逐一看選項
一組包含 n 個數字的集合與數字 i
同時提供資料與目標順位，資訊完整。

僅一組 n 個數字
只給集合，無法知道要最小、中位數，還是其他順位。

僅數字 i
只給 i，沒有資料可供比較。

一個已排序陣列
已排序陣列是特殊情況；一般輸入不必排序，而且仍需知道 i。

## L7-2472｜L7

下列何者是中位數（Median）的定義？

本題答案：「第 n/2 個順序統計量」

解題思路與過程
先排序，再找中央。例：六個數排序為 [2,4,7,9,11,15]，中央兩個是第 3 小的 7 與第 4 小的 9。
本題答案 「第 n/2 個順序統計量」 採「下中位數」的簡寫：偶數 n 時取第 n/2 小，所以此例取 7。若採統計學常用的兩中央值平均則是 8；若取上中位數則是 9。奇數 n＝5 時，應取第 (n+1)/2＝3 小，不能取非整數的第 2.5 小。

逐一看選項
第 n/2 個順序統計量
依本題的下中位數慣例作答；n/2 不是所有 n 與所有中位數定義都適用的公式。

最小值
最小值是第 1 小，通常不在中央。

最大值
最大值是第 n 小，通常不在中央。

總和
總和是把所有值相加，沒有找中央位置。

## L7-2479｜L7

**********若 n=1，集合的第 1 個順序統計量即為？

本題答案：「唯一的元素」

解題思路與過程
只有一個數時，不必比較。例：A＝[37]，排序後仍是 [37]，第 1 小只能是 37。
這也是 SELECT 的遞迴終止條件：目前範圍只剩一格 p＝r，就直接回傳 A[p]。

逐一看選項
唯一的元素
唯一元素同時是最小值、最大值與中位數。

為 0
除非那個元素本身恰好是 0，否則不能回傳 0。

無窮大
無窮大不是輸入中的那個有限數。

不確定
已有唯一元素與合法順位，答案可以確定。

## L7-2481｜L7

**********順序統計量問題通常屬於哪類演算法應用？

本題答案：「選擇問題」

解題思路與過程
「找第 i 小」只需要交出一個指定排名的值，所以稱為選擇問題。
例如找 [9,2,7,4] 的第 2 小，只需回傳 4。把全體排成 [2,4,7,9] 也能解，但做了超出題目要求的工作。

逐一看選項
選擇問題
指定順位、找出對應元素，正是 selection。

排序問題
排序要求所有元素都按大小排列；這裡只要求一個順位。

圖論
題目沒有頂點與邊的關係。

字串處理
題目處理大小排名，沒有字串比對或字元結構。

## L7-2484｜L7

順序統計量演算法中，處理 n 個元素時，n 通常假設為？

本題答案：「大於 0 的正整數」

解題思路與過程
n 是資料有幾個，例如 [8,3,5] 有 n＝3。要找第 i 小，集合至少要有一個元素，而且必須有 1≤i≤n。
空集合 n＝0 可在程式中另行處理，但沒有合法的第 1 小。

逐一看選項
大於 0 的正整數
有限個元素且至少一個，因此是正整數。

負數
元素個數不能是負數。

複數
個數必須可逐一數出，不能是複數。

無限大
一般演算法輸入是有限資料，不是無限多個元素。

## L7-2485｜L7

尋找中位數是一種？

逐一看選項
選擇問題

插值問題

雜湊問題

圖形掃描

## L7-2487｜L7

順序統計量中的 i 是指？

i 是「在目前這批數裡找第幾小」。它與陣列索引是兩回事。
例：目前範圍 A[4..9] 有六個元素，i＝2 代表找這六個數的第 2 小，並不是直接讀 A[2]。若分割後 pivot 在 q＝6，則 pivot 的區域順位 k＝6−4+1＝3。

逐一看選項
查詢的排名順序
i 表示目標排名。

陣列的大小
目前元素數是 r−p+1，整體大小常記為 n。

pivot 的索引
pivot 的陣列索引記作 q；區域順位才是 k＝q−p+1。

比較次數
比較次數是執行成本，不是要求的排名。

Minimum

Sorting

## L7-2493｜L7

## L7-2496｜L7

以下哪些屬於順序統計量應用？

共同點是依大小或優先順序，挑出某個排名附近的元素。

逐一看選項
排程系統中的優先級處理

統計學中的四分位數計算
四分位數依排序位置定義，可能另有插值慣例。

資料集的中位數分析
中位數直接對應中央順位。

## L7-2498｜L7

在中位數問題中，對於 n 為偶數的處理？

解題思路與過程
偶數個數沒有唯一一個正中央位置。例：[2,4,7,9,11,15] 的中央是第 3、4 個，也就是 7 與 9。
下中位數取 7；上中位數取 9；中央兩數平均取 (7+9)/2＝8。三種約定不同，看到題目必須先確認採哪一種。

逐一看選項
可定義為兩個中位數的平均
統計學常用中央兩數的平均，本例為 8。

選取第 n/2 個元素
取第 n/2＝3 小，是下中位數 7。

選取第 n/2+1 個元素
取第 n/2+1＝4 小，是上中位數 9。

不定義
偶數情況仍可定義中位數，只需說明採哪個慣例。

## L7-2499｜L7

順序統計量演算法常見複雜度？

本題答案：「O(n)」、「O(n log n)」、「O(n²)」

解題思路與過程
這題比較的是不同解法與不同情況，不是說同一次執行同時具有三種緊確複雜度。
找一個順位可用：確定性 SELECT 最壞 Θ(n)；先做有效率的比較排序再取值 Θ(n log n)；Randomized-Select 若反覆極端分割，最壞 Θ(n²)。

逐一看選項
O(n)
線性選擇演算法可達成；隨機選擇的期望時間也是線性。

O(n log n)
先完整比較排序再取順位，是常見但較多工作的解法。

O(n²)
極端分割的隨機選擇會退化成平方時間。

O(1)
任意未排序資料一般不能只看固定幾格就找到指定順位；已排序後讀一格才是 O(1)。

## L7-2501｜L7

順序統計量與排序的關係？

本題答案：「排序後的陣列可直接取得順序統計量」、「排序時間複雜度為 O(n log n)」、「順序統計量可透過排序間接得到」

解題思路與過程
排序提供全部排名，選擇只需要其中一個。例：[9,2,7,4] 排成 [2,4,7,9] 後，第 3 小可直接讀第 3 格，得到 7。
若只查一次順位，可考慮線性選擇；若要反覆查很多順位，先排序的成本可能值得。

逐一看選項
排序後的陣列可直接取得順序統計量
排序後位置就對應大小排名，讀指定位置可用 O(1)。

排序時間複雜度為 O(n log n)
本題指 merge sort、heap sort 等有效率的比較排序；不是宣稱所有排序法都必定 O(n log n)。

順序統計量可透過排序間接得到
先排序再取第 i 個，的確是一種解法。

兩者無任何關係
兩者透過排名直接相關，不能說沒有關係。

## L7-2469｜L7

尋找集合中最小值（Minimum）的基本演算法時間複雜度為？

本題答案：「O(n)」

解題思路與過程
先拿第一個數當目前最小值，再依序檢查剩下 n−1 個。
例：[8,3,5,1]：min＝8；比 3 後變 3；比 5 後仍為 3；比 1 後變 1。共 3＝n−1 次比較，因此時間隨 n 線性成長。

逐一看選項
O(n)
基本掃描是 Θ(n)，所以選 O(n)。

O(log n)
沒有排序等額外資訊時，不能每次砍掉一半資料。

O(n log n)
O(n log n) 是寬鬆上界，但題目問基本演算法的代表性成長率；緊確答案是線性，不需先排序。

O(1)
未查看的元素可能更小，不能只做固定次數的工作。

## L7-2470｜L7

要在一個有 n 個元素的集合中同時找到最小值與最大值，最有效率的比較次數大約為？

本題答案：「1.5n」

解題思路與過程
關鍵是每兩個數共用一次比較。先比較這對數，較小者只需挑戰 min，較大者只需挑戰 max：一對兩個元素只要 3 次。
例 n＝6：第一對 [8,3] 比 1 次建立 min＝3、max＝8；第二對 [5,1] 比 3 次；第三對 [9,4] 再比 3 次。合計 7＝3×6/2−2，而分別掃描要 10 次。
偶數 n 的精確式為 1+3(n−2)/2＝3n/2−2；奇數 n 為 3(n−1)/2。題目問「大約」，取主項 1.5n。

逐一看選項
1.5n
兩個元素共用 3 次比較，主項是 3n/2。

2n
約 2n 是分別找最小與最大，未利用配對省比較。

n
一般 n 下只約 n 次不足以同時確認兩個極值；特殊小 n 不代表一般公式。

n log n
完整排序會做更多工作，不是這裡最佳比較次數。

## L7-2483｜L7

若以兩兩比較的方式，尋找最小值需要進行幾次比較？

本題答案：「n-1」

解題思路與過程
每一次大小比較，最多淘汰一個「可能是最小值」的候選者。從 n 個候選者淘汰到剩 1 個，至少需要 n−1 次。
直接掃描也剛好做到 n−1 次，因此既必要又足夠。例 n＝4，只要依序用目前最小值與另外三個數比較，共 3 次。

逐一看選項
n-1
n−1 剛好把 n 個候選縮成 1 個。

n
第一個元素用來初始化，不需再多算一次比較。

n/2
只配對一次會留下約 n/2 個勝者，還沒決定最小值。

1
只有 n＝2 才剛好一次；一般 n 不成立。

## L7-2488｜L7

尋找最小值與最大值的優化方法包含？

本題答案：「配對比較法」、「直接掃描」

解題思路與過程
目標只有兩個極值，不必把全部數排好。直接掃描可一路維護 min、max；配對法再利用「較小者不可能是最大、較大者不可能是最小」節省比較。
例如 n＝6，分別掃描要 2n−2＝10 次，配對法只要 3n/2−2＝7 次。兩者時間都是 Θ(n)，但比較次數不同。

逐一看選項
配對比較法
配對後每兩個新元素只用 3 次比較，是本章的改善方法。

直接掃描
直接掃描是線性、常數輔助空間的基本有效方法；不代表比較數也等於配對法。

使用堆積
堆積可用於其他選擇需求，但本題從原始陣列找兩個極值不必另建堆，也未因此獲得本章的比較數優勢。

先排序
先排序能求極值，卻多做了中間所有排名的工作，不是此題要的優化。

## L7-2494｜L7

比較次數分析中，同時尋找最大值與最小值的好處？

本題答案：「減少總比較次數」、「提升效率」

解題思路與過程
各自找最小、最大要 (n−1)+(n−1)＝2n−2 次比較。配對後先分出每對大小，只讓較小者競爭 min、較大者競爭 max，偶數 n 改為 3n/2−2。
例如 n＝100：各自掃描 198 次；配對 148 次，少了 50 次。兩者仍都是線性時間，改善的是比較數與常數成本。

逐一看選項
減少總比較次數
共用每對的第一次比較，總數確實減少。

提升效率
在比較有成本的模型下，少比較能降低工作量。

簡化程式邏輯
配對需要奇偶初始化與分支，程式不一定更簡單。

減少記憶體使用
兩種掃描都可只用 min、max 等常數空間，沒有必然更省記憶體。

## L7-2506｜L7

為什麼最小/最大值演算法比較有效率？

本題答案：「利用配對比較特性」、「降低比較總數」、「不需進行完整排序」

解題思路與過程
只求兩端，不求中間的完整排序。配對 (3,8) 後，3 只需跟目前 min 比，8 只需跟目前 max 比；不用讓兩者都各比一次 min 與 max。
因此每對用 3 次而不是 4 次比較，全部仍只需 Θ(n) 時間與 O(1) 輔助空間。

逐一看選項
利用配對比較特性
配對產生大小關係，可排除不必要的極值挑戰。

降低比較總數
兩個元素共用一次比較，降低總比較數。

不需進行完整排序
min、max 不需要知道其他元素彼此的完整順序。

直接記憶陣列值
只是把值記起來沒有建立大小關係，不能解釋為什麼比較數減少。

## L7-2475｜L7

在尋找第二小元素（Second smallest）時，最壞情況下需要的比較次數為？

本題答案：「n + ⌈log n⌉ - 2」

解題思路與過程
把數字辦淘汰賽，每場由較小者晉級。找到總冠軍最小值，需要 n−1 場。
第二小一定曾「直接輸給最小值」：若它輸給別人，那個人比它小，加上總冠軍，就不可能是第二小。平衡賽程中，冠軍最多打 ⌈log₂ n⌉ 場，因此只需在這些直接敗者裡找最小，再比 ⌈log₂ n⌉−1 次。
合計 (n−1)+(⌈log₂ n⌉−1)＝n+⌈log₂ n⌉−2。例 n＝8，用 7 場決定最小；冠軍的 3 個直接敗者再比 2 場，共 9 次。

逐一看選項
n + ⌈log n⌉ - 2
與淘汰賽加上直接敗者的小比賽相符；本章 log 以 2 為底。

n
只約 n 次沒有完整計入找第二小的額外比較；某些小 n 數值巧合不等於一般公式。

2n
分開掃描可以做到約 2n，但不是題目要的最佳最壞比較數。

log n
log n 只是冠軍一路遇到的對手數，還沒算全體淘汰賽。

## L7-2502｜L7

尋找第二小元素的步驟？

解題思路與過程

第一輪：3 勝 8、1 勝 5、4 勝 9、6 勝 7；第二輪：1 勝 3、4 勝 6；決賽：1 勝 4。最小值是 1，直接輸給它的是 [5,3,4]，所以第二小就是這三個數的最小值 3。

## L7-2476｜L7

Randomized-Select 中的 Partition 操作目的是？

依 pivot 分出大小兩側，是 Partition 的目的。

排序陣列

尋找最大值
除非目標剛好最大，否則分割本身不直接求最大。

計算總和
不需要把元素加總。

## L7-2482｜L7

在 Partition 之後，pivot 元素位於？

本題答案：「其正確的順序位置」

解題思路與過程
本題採會把 pivot 放回最終位置的 Partition 版本。例：[9,2,7,4,6] 以 6 為 pivot，分成 [2,4]｜6｜[9,7]，6 的最終索引是第 3 格。
因為剛好有兩個數比 6 小，即使兩側繼續排序，6 仍會留在第 3 格。這個保證只針對 pivot，不代表其他元素都已歸位。

逐一看選項
其正確的順序位置
在目前處理範圍內，pivot 已到排序後應在的位置。

陣列開頭
只有 pivot 恰為目前最小時才可能在開頭。

陣列結尾
只有 pivot 恰為目前最大時才可能在結尾。

隨機位置
選 pivot 可以隨機，分割完成的位置卻由大小關係決定。

## L7-2500｜L7

Partition 操作中，哪些索引會變動？

本題答案：「i」、「j」

解題思路與過程
依本題的 Lomuto 寫法，j 負責從左到右讀元素，i 表示「小於等於 pivot 的區域」右邊界。pivot 值先固定，最後才歸位。
例：[9,2,7,4,6]，pivot＝6：j 看 9 時 i 不動；看 2 時 i 前進並交換；看 7 時不動；看 4 時 i 再前進。最後把 6 放到大小兩區的交界。

逐一看選項
i
i 隨找到符合條件的元素而前進，維護小值區邊界。

j
j 每輪移到下一個待檢查元素。

pivot
此處 pivot 是選定的基準值，不是掃描用的移動索引；最後搬動基準值不改變這個分工。

陣列長度
分割只交換現有元素，不改變長度。

## L7-2507｜L7

Select 演算法中的 Partition 操作？

解題思路與過程

與 Quicksort 中的類似

重新排列元素

## L7-2473｜L7

Randomized-Select 演算法是基於哪種排序演算法的變形？

本題答案：「Quicksort」

解題思路與過程
Quicksort：選 pivot → Partition → 兩側都遞迴排序。

Quicksort

Merge Sort
Merge Sort 將兩半排序後合併，不靠 pivot 分大小。

Insertion Sort
Insertion Sort 逐一插入已排序區，不使用此分割流程。

## L7-2474｜L7

Randomized-Select 的平均時間複雜度為？

本題答案：「O(n)」

解題思路與過程
每次 Partition 仍要掃描目前範圍，但之後只留下目標那一邊。隨機 pivot 讓反覆留下幾乎全部資料的壞路徑不容易持續出現，期望總工作量為 Θ(n)。
先用平衡情況建立直覺：n+n/2+n/4+…<2n。真正的期望分析不要求每次都剛好平分；隨機執行仍可能遇到平方時間的個別路徑。

逐一看選項
O(n)
平均／期望的緊確成長率是線性，因此選 O(n)。

O(n²)
平方時間是反覆極端分割的最壞情況，不是期望值。

O(log n)
遞迴層數可能約 log n，但每層要掃描多個元素，不是每層只做一次操作。

O(n log n)
平衡 Quicksort 兩側都做才是 n log n；Select 只走一側。

## L7-2477｜L7

Randomized-Select 在最壞情況下的時間複雜度為？

本題答案：「O(n²)」

解題思路與過程
假設要找最大值，卻每次都抽到目前最小值當 pivot。第一次掃 n 個，只排除 1 個；接著掃 n−1、n−2……。
總工作量與 n+(n−1)+…+1＝n(n+1)/2 同階，所以最壞為 Θ(n²)。隨機化讓這條路徑機率很低，但沒有使它不可能。

逐一看選項
O(n²)
極端分割反覆出現，等差級數總和為平方級。

O(n)
線性是期望表現，或有品質保證的確定性 Select 最壞表現。

O(log n)
只算遞迴層數會漏掉每次分割的掃描成本；這條路徑層數也不是對數。

O(n log n)
這是平衡完整排序的常見成本，不是本題極端單側遞迴的總和。

## L7-2478｜L7

在目前範圍 p..r 內隨機抽一個索引，把那個值當 pivot；常見做法再將它與 A[r] 交換，交給一般 Partition。

逐一看選項

隨機挑選目前範圍的元素，是名稱中 Randomized 的來源。

固定選第一個是另一種規則，沒有隨機性。

## L7-2491｜L7

## community-ff4cc29e-e524-4859-9764-a5b597317e87-6｜L6

在決策樹模型中，樹的高度代表了？

比較排序的決策樹中，一個內部節點代表一次比較，每條分支代表比較結果。從根走到某個葉節點，就是處理某種輸入排列所做的一串比較；最長根到葉路徑的長度即樹高，代表最壞情況的比較次數。葉節點數是可區分的輸入排列數，與高度不是同一個量。

## community-0c193f84-655e-4d7e-b5c4-7d6a80a0668f-2｜L2

## community-0c193f84-655e-4d7e-b5c4-7d6a80a0668f-3｜L2

## community-0c193f84-655e-4d7e-b5c4-7d6a80a0668f-9｜L2

演算法分析中，通常專注於尋找「最壞情況執行時間」（Worst-case running time）的原因有哪些？

最壞時間是同樣輸入大小下所有合法輸入中的最大成本，可提供「不論收到哪種輸入都不超過此界」的保證。有些工作常遇到較差排列；例如插入排序的反向輸入是平方時間，而均勻隨機排列的平均時間也同為 Θ(n²)，雖然常數不同。

展開遞迴樹：第 0 層成本 cn；第 1 層有 2 個大小 n/2 的子問題，合計 2×c(n/2)＝cn；第 2 層仍合計 cn。子問題大小 n/2ʰ 到 1 時，h＝log₂ n，因此各內部層合計 Θ(n log n)，葉節點另有 Θ(n)，總體仍是 Θ(n log n)。本題填 big-theta(nlogn)。

## community-eaa5c327-54c5-4ccc-9493-ffe58921eb52-10｜L2

下列關於漸進符號對稱性（Symmetry）與轉置對稱性（Transpose Symmetry）的敘述，哪些是正確的？

Θ 的兩側常數倍界可反過來寫，所以 f＝Θ(g) 等價於 g＝Θ(f)。上界反轉後是下界，因此 f＝O(g) 等價於 g＝Ω(f)；嚴格相對較小的小 o，反轉後對應嚴格較大的小 ω。

O 本身不對稱：n＝O(n²)，但 n² 並不是 O(n)，因為 n²/n＝n 不受固定常數限制。可用這個例子排除「O 交換兩邊仍是 O」的敘述。

## community-eaa5c327-54c5-4ccc-9493-ffe58921eb52-2｜L2

若滿足 m <= n 則 f(m) >= f(n)，此函數性質稱為 ____________ 。(請用英文小寫回答，單字間留一空白)

填 monotonically decreasing，按本題的非嚴格不等號，精確意思是「單調不遞增」：輸入由 m 增到 n，函數值不會增加，也允許持平。例如 f(n)＝1/n 隨 n 增加而下降，常數函數也符合不遞增。若要求嚴格遞減，條件需在 m<n 時改成 f(m)>f(n)，不能混為一談。

## community-eaa5c327-54c5-4ccc-9493-ffe58921eb52-3｜L2

分析演算法（Analyzing algorithms）時，通常需要預測演算法所需的哪些資源？

在一般軟體分析中，時間與記憶體是最常見的成本；在分散式演算法中還會計算通訊資料量或頻寬需求，在電路模型或硬體實作中可分析邏輯閘數。老師將這四種資源模型都列入，並不是說每一道普通排序題都必須同時計算所有硬體成本。先選定分析模型，才知道要數哪些操作或空間。

## community-eaa5c327-54c5-4ccc-9493-ffe58921eb52-4｜L2

表示重複對數函數（Iterative logarithm function）的數學寫法為 ____________ 。(請用小寫英文回答)

填 lg*(n)，讀作 iterated logarithm（重複對數）。它計算對 n 反覆取以 2 為底的對數，要幾次才降到 1 或以下。例：16→4→2→1，共 3 次，所以 lg*16＝3。它不是 log n 的某次方，也不是 log(log n) 固定只做兩次；星號表示一直重複到指定門檻。

## community-eaa5c327-54c5-4ccc-9493-ffe58921eb52-5｜L2

若一個函數滿足 f(n) = ____________ ，則稱此函數是多項式有界。(請用英文回答，表示形式為 請用log，不可用lg替代log，上標請用^ 指數符號 用 k)

填 O(n^k)，其中 k 必須是與 n 無關的固定常數。多項式有界指 f(n) 最終被某個固定次方 n^k 的常數倍壓住，例如 n² log n＝O(n³)。若讓 k 隨 n 增長，就不再是這個定義；例如 2ⁿ 不會被任何固定次方的 n 永遠壓住。

## community-eaa5c327-54c5-4ccc-9493-ffe58921eb52-6｜L2

在計算機科學中，若無特別註明，常數「lgn」通常表示以下列哪一個數為底的對數？

本課慣例 lg n 表示 log₂ n，底數為 2；ln n 通常表示自然對數 logₑ n，log₁₀ n 則明寫底數或依其他領域慣例。例：lg 8＝3，因為 2³＝8。漸進分析中不同固定底數只差常數倍，但要填具體對數值或遞迴高度時，底數仍需認清。

## community-eaa5c327-54c5-4ccc-9493-ffe58921eb52-7｜L2

非漸進緊確的上界（Upper bound that is not asymptotically tight）是用下列哪一個符號表示？

本題填小 o。當 g(n) 最終為正，f(n)＝o(g(n)) 表示對每個正常數 c，n 足夠大時都有 f(n)<cg(n)；常見判斷是 f(n)/g(n)→0。例如 n＝o(n²)。

大 O 只保證某個常數倍上界，也可能剛好同階；小 o 給出嚴格較慢的相對成長。一般口語的「不緊確上界」不必然等同小 o，這裡採教材此題用語。Ω 與 ω 則是下界方向。

## community-eaa5c327-54c5-4ccc-9493-ffe58921eb52-8｜L2

對於任何常數 a > 1，當 n 趨近於無窮大時，多項式函數與指數函數的關係極限值為（n^b / a^n）？

固定 a>1 與固定 b 時，指數 aⁿ 的成長最終超過多項式 nᵇ，所以比值 nᵇ/aⁿ 趨近 0。可取對數觀察：ln(nᵇ/aⁿ)＝b ln n−n ln a，其中 n ln a 最終主導，使結果趨近負無窮，原比值便趨近 0。不能只比較某個小 n 時誰較大。

## community-eaa5c327-54c5-4ccc-9493-ffe58921eb52-9｜L2

對於所有實數 x，下列關於指數函數的性質哪些是正確的？

eˣ≥1+x 對所有實數 x 成立，在 x＝0 取等號；固定 x 時，limₙ→∞(1+x/n)ⁿ＝eˣ 也成立。eˣ 並非永遠小於 1，例如 x＝1 時 e>1。

老師答案保留，但「|x|≤1 時 eˣ≤1+x+x²/2」照原式並不對所有該區間的 x 成立：取 x＝1，左邊約 2.718，右邊為 2.5，直接得到反例。當 0<x≤1，泰勒展開還有正的 x³/6 等項，不能用二次截斷式作這種上界。若要成立，需另補適當條件或餘項界；解析不把錯誤不等式當成通則。

## community-0c87fc9b-213e-4bf2-8df6-18900897aaa2-1｜L2

史特林近似公式（Stirling's approximation）指出阶乘 n! 的增長趨勢。寫成極限與漸進公式時，log(n!) = ____________ 。(請用英文回答，表示形式為 請用log，不可用lg替代log，上標請用^，符號請用 {big-theta, theta, big-omega, omega, O, o,})

log(n!)＝Σₖ₌₁ⁿ log k。上界：每項都≤log n，所以總和≤n log n。下界：後半約 n/2 項都≥log(n/2)，因此總和≥(n/2)log(n/2)。上下界同為 n log n 的常數倍，得到 Θ(n log n)，填 big-theta(nlogn)。這也與 Stirling 公式取對數後的主項一致。

## community-0c87fc9b-213e-4bf2-8df6-18900897aaa2-2｜L2

當一個函數 f(n) 同時滿足 O(g(n)) 且 Ω(g(n)) 時，我們說 g(n) 是 f(n) 的漸進緊確界，其符號為 ____________ 。(請用英文回答，表示形式為 請用log，不可用lg替代log，上標請用^，符號請用 {big-theta, theta, big-omega, omega, O, o,})

Θ(g(n)) 同時要求上界與下界：存在正常數 c₁、c₂ 與門檻 n₀，使所有 n≥n₀ 都有 c₁g(n)≤f(n)≤c₂g(n)。因此「f(n)＝O(g(n))」與「f(n)＝Ω(g(n))」合在一起，正好是 Θ(g(n))。

小 o 表示相對成長率嚴格較小，小 ω 表示嚴格較大，不是同階所需的兩側常數倍界。例：3n+2 與 n 同階，但不是 o(n)，也不是 ω(n)。

## community-0c87fc9b-213e-4bf2-8df6-18900897aaa2-3｜L2

若滿足 m <= n 則 f(m) <= f(n)，此函數性質稱為何者？

m≤n 時有 f(m)≤f(n)，表示輸入增加時函數值不會下降，是單調不遞減；本題選 Monotonically increasing。例：[1,1,3,5] 允許連續相等，仍符合非嚴格單調。Strictly increasing 要求 m<n 時 f(m)<f(n)，會排除持平段，因此比題幹條件更強。
