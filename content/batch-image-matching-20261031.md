# 批次查題：圖片內容比對

批次查題可先選取 HTML 附帶的 `_files` 資料夾，再匯入 HTML。每張參考圖片計算 SHA-256，題庫圖片也從既有公開圖片端點下載後計算；本機題圖不會上傳。圖片順序、內容、完整題幹、題型與選項均相符且題庫答案一致時才帶入答案。

題圖身份隨原題號、題幹及選項保存於本機草稿。附加題目、題號重新編排、重新開啟草稿皆保留身份；修改文字或選項後不會沿用舊題圖。缺圖、同名歧義、圖片變動、不可辨識文字及答案衝突均維持未收錄結果。縮放、重新壓縮或裁切後的圖片不視為相同檔案。

驗證：使用使用者提供的挖寶挑戰 HTML 與附帶圖片資料夾，24 題全部讀入，12 題附有圖片內容身份；公開挖寶題庫的 28 筆含圖版本可讀取並計算身份。經過匯入、套用文字、草稿序列化還原與完整查題流程，24／24 題比對成功。

60 項圖片、HTML 匯入、介面、草稿與載入測試通過。較廣的題庫模型測試共 36 項中有 5 項在本次修改前即失敗；以 HEAD 原始模型重跑也有相同 5 項失敗，修改後仍為 31 通過、5 失敗。這些既有題庫答案與版本差異未在本次修改。驗證使用檔案解析與 DOM 測試，未以桌面瀏覽器操作檔案選擇器。

## 題庫圖片載入補強

發現遠端題圖單次讀取失敗會排除完整原題，只留下不同條件的相似候選。現改為明確 CORS 請求、重新載入圖片快取、每張圖最多嘗試兩次，並為持續讀取失敗的原題顯示重新同步提示。以整頁 DOM 流程載入使用者原始 HTML 與圖片資料夾，並刻意使 SJF 原題圖片第一次讀取失敗，第二次成功後結果為已收錄 24、未收錄 0，題目第 1 題對到 community-31668494-b954-40b4-b0ee-614fffc0d46c-2，答案 (8.2)。這重現並修正了載入失敗的行為；未取得使用者當次瀏覽器網路紀錄，故不將快取或暫時網路失敗斷言為唯一原因。
