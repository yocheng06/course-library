## 新排序第 20 題｜SJF／SRTF 計算

原題：已知有以下的行程 與其CPU時間 與 到達時間

若在不可搶先(nonpreemptive)的情況下，SJF 的的執行順序為合 ____________ (格式:CDEAB)

老師答案：(ADCEB)

先認清本題在問：CPU 執行順序。

① 先用規則決定誰能上 CPU
不可搶先 SJF：CPU 空下來才選「已到達且 CPU 時間最短」的人；沒做完前不換人。
題圖的（CPU 時間，到達時間）為 A（5，0）、B（4，1）、C（2，2）、D（1，3）、E（3，7）。不可搶先表示 A 即使遇到較短的新工作，也要做完才換人；同樣地，7 ms 到達的 E 不會插斷正在執行的 C。
單一 CPU；不計切換耗時；沒有額外 I/O。 同樣長的工作採先到先做；尚未到達者不參加挑選。

② 一步一步排時間線
0 ms：目前可執行 A（需要 5 ms）。依規則選 A，所以開始執行 A。
5 ms：目前可執行 B（需要 4 ms）、C（需要 2 ms）、D（需要 1 ms）。依規則選 D，所以開始執行 D。
6 ms：目前可執行 B（需要 4 ms）、C（需要 2 ms）。依規則選 C，所以開始執行 C。
8 ms：目前可執行 B（需要 4 ms）、E（需要 3 ms）。依規則選 E，所以開始執行 E。
11 ms：目前可執行 B（需要 4 ms）。依規則選 B，所以開始執行 B。

時間線（括號內是開始–結束，單位 ms）：
A（0–5） → D（5–6） → C（6–8） → E（8–11） → B（11–15）

③ 只計算這一題問的量
沿時間線由左往右抄每個連續區塊：A → D → C → E → B。同一行程被搶先後再次回來，要再寫一次；不要把重複名稱刪掉。

④ 對照答案
本題結論：A → D → C → E → B。

容易弄混的地方：不能在 0 ms 先挑全表最短的 D，因為 D 要到 3 ms 才到達。A 做完後是 D→C→E→B；依題目要求連寫成 ADCEB，不加空白或分隔號。

## 新排序第 40 題｜Round Robin 計算

原題：採用 RR（Round Robin）排程

Process Arrival Time Burst Time
P1 0 10
P2 2 4
P3 4 6
P4 6 3
P5 8 5

Time Quantum = 3 ms Average Waiting Time =? ____________

老師答案：(12.6)

先認清本題在問：平均等待時間。

① 先用規則決定誰能上 CPU
RR：依就緒佇列輪流，每次最多做一個時間片；未完成的人回隊尾。 本題每輪最多 3 ms。
這題問平均等待時間。先排完 RR 時間線，記下每個行程最後完成的時刻，再各自扣掉到達時間與真正執行 CPU 的時間。
單一 CPU；不計切換耗時；沒有額外 I/O。 時間片＝3 ms；邊界時新到達者先入隊，再把用完時間片的工作放回隊尾；同時到達依表格順序。

② 一步一步排時間線
0–3：P1 做 3 ms，還剩 7 ms，回到隊尾；接下來的隊列是 P2 → P1。
3–6：P2 做 3 ms，還剩 1 ms，回到隊尾；接下來的隊列是 P1 → P3 → P4 → P2。
6–9：P1 做 3 ms，還剩 4 ms，回到隊尾；接下來的隊列是 P3 → P4 → P2 → P5 → P1。
9–12：P3 做 3 ms，還剩 3 ms，回到隊尾；接下來的隊列是 P4 → P2 → P5 → P1 → P3。
12–15：P4 做 3 ms，已完成，離開佇列；接下來的隊列是 P2 → P5 → P1 → P3。
15–16：P2 做 1 ms，已完成，離開佇列；接下來的隊列是 P5 → P1 → P3。
16–19：P5 做 3 ms，還剩 2 ms，回到隊尾；接下來的隊列是 P1 → P3 → P5。
19–22：P1 做 3 ms，還剩 1 ms，回到隊尾；接下來的隊列是 P3 → P5 → P1。
22–25：P3 做 3 ms，已完成，離開佇列；接下來的隊列是 P5 → P1。
25–27：P5 做 2 ms，已完成，離開佇列；接下來的隊列是 P1。
27–28：P1 做 1 ms，已完成，離開佇列；接下來的隊列是 空。

時間線（括號內是開始–結束，單位 ms）：
P1（0–3） → P2（3–6） → P1（6–9） → P3（9–12） → P4（12–15） → P2（15–16） → P5（16–19） → P1（19–22） → P3（22–25） → P5（25–27） → P1（27–28）

③ 只計算這一題問的量
等待＝完成－到達－CPU 時間。
P1：28－0－10＝18 ms。
P2：16－2－4＝10 ms。
P3：25－4－6＝15 ms。
P4：15－6－3＝6 ms。
P5：27－8－5＝14 ms。
平均＝（18＋10＋15＋6＋14）÷5＝12.6 ms。

④ 對照答案
本題結論：12.6。

容易弄混的地方：P1 雖然 0 ms 就第一次上 CPU，之後仍會回隊尾等待，所以總等待不是 0。五個等待值為 18、10、15、6、14；這和平均回應時間 4 ms、平均迴轉時間 18.2 ms 是不同的量。

## 新排序第 42 題｜Round Robin 計算

原題：Round Robin (RR) 排程

Process Arrival Time Burst Time
P1 0 8
P2 1 4
P3 2 6
P4 3 1

If RR Scheduling is used with TQ = 3, Please write down the completed time of the processes P1, P2, P3, P4 ____________ Answer format: 10,15,4,6

老師答案：(19),(14),(17),(10)

先認清本題在問：每個行程的完工時刻。

① 先用規則決定誰能上 CPU
RR：依就緒佇列輪流，每次最多做一個時間片；未完成的人回隊尾。 本題每輪最多 3 ms。
completed time 問的是每個行程最後完成時的時鐘讀數，不是等待時間，也不是第一次上 CPU 的時刻。3 ms 邊界到達的 P4 先入隊，再把用完時間片的 P1 放回隊尾。
單一 CPU；不計切換耗時；沒有額外 I/O。 時間片＝3 ms；邊界時新到達者先入隊，再把用完時間片的工作放回隊尾；同時到達依表格順序。

② 一步一步排時間線
0–3：P1 做 3 ms，還剩 5 ms，回到隊尾；接下來的隊列是 P2 → P3 → P4 → P1。
3–6：P2 做 3 ms，還剩 1 ms，回到隊尾；接下來的隊列是 P3 → P4 → P1 → P2。
6–9：P3 做 3 ms，還剩 3 ms，回到隊尾；接下來的隊列是 P4 → P1 → P2 → P3。
9–10：P4 做 1 ms，已完成，離開佇列；接下來的隊列是 P1 → P2 → P3。
10–13：P1 做 3 ms，還剩 2 ms，回到隊尾；接下來的隊列是 P2 → P3 → P1。
13–14：P2 做 1 ms，已完成，離開佇列；接下來的隊列是 P3 → P1。
14–17：P3 做 3 ms，已完成，離開佇列；接下來的隊列是 P1。
17–19：P1 做 2 ms，已完成，離開佇列；接下來的隊列是 空。

時間線（括號內是開始–結束，單位 ms）：
P1（0–3） → P2（3–6） → P3（6–9） → P4（9–10） → P1（10–13） → P2（13–14） → P3（14–17） → P1（17–19）

③ 只計算這一題問的量
P1 的最後一段結束在 19 ms，所以完工時刻是 19。
P2 的最後一段結束在 14 ms，所以完工時刻是 14。
P3 的最後一段結束在 17 ms，所以完工時刻是 17。
P4 的最後一段結束在 10 ms，所以完工時刻是 10。
最後依題目指定的行程名稱順序填入：19 → 14 → 17 → 10。

④ 對照答案
本題結論：19、14、17、10。

容易弄混的地方：CPU 的完成先後是 P4→P2→P3→P1，但題目要求按 P1、P2、P3、P4 列答案，因此依序填 19、14、17、10；不要改成按完成先後排列。
