## L6-014

計數排序(Counting Sort)中，陣列 C 的作用是？

核心觀念：
把 C 想成每種數字的登記表。例：A＝[2,0,2,1]，數完得到 C[0..2]＝[1,1,2]，表示 0 有 1 個、1 有 1 個、2 有 2 個。累加後變成 [1,2,4]，表示小於等於 0、1、2 的數分別有 1、2、4 個。回填時 C 又會隨使用而遞減，所以一定先看演算法做到哪個階段。

選項判讀：
A．儲存指標：不選。C 的每格存整數計數／位置界線，不是記憶體指標。
B．儲存每個鍵的出現次數或累積計數：選這項。符合這一階段 C 所記錄的計數資訊。
C．儲存原始資料：不選。原始資料在 A；C 不會把 A 的全部元素依原順序再存一遍。
D．作為樞紐：不選。樞紐是快速排序等方法的角色，計數排序沒有挑 pivot。

本題答案：B. 儲存每個鍵的出現次數或累積計數。

## L6-062

計數排序中的 C[i] 儲存的是？

核心觀念：
本題依題庫既有條件，問的是「累積計數已做完、尚未開始回填」的 C[i]。例如 A＝[2,0,2,1]，累積後 C＝[1,2,4]；C[1]＝2，因為 0 和 1 這兩個元素都小於等於 1。若只數等於 1 的次數，才會得到 1，那是累積前的表。

選項判讀：
A．指向元素 i 的指標：不選。C 的每格存整數計數／位置界線，不是記憶體指標。
B．小於或等於 i 的元素總數：選這項。符合這一階段 C 所記錄的計數資訊。
C．元素 i 的位置：不選。C[i] 此時是累積總數，也是值 i 所占區段的右界；不是第 i 個輸入元素的單一位置。
D．元素 i 的具體值：不選。i 是數值索引，C[i] 不是把數字 i 自己存進去。

本題答案：B。

## L6-017

計數排序(Counting Sort)的空間複雜度主要取決於？

核心觀念：
先看題目在強調哪一塊空間。計數表 C 要替 0～k 每種數字留一格，所以有 k＋1 格，為 Θ(k)；範圍越大，C 越大。輸出 B 另外需要 n 格。因此本題答案強調計數表取決於 k；若問整個穩定版本的輔助空間，必須回答 Θ(n＋k)，不能說 n 完全不影響。

選項判讀：
A．遞迴深度：不選。這個版本沒有遞迴呼叫或樹結構，空間不由這些量決定。
B．樹的高度：不選。這個版本沒有遞迴呼叫或樹結構，空間不由這些量決定。
C．輸入長度 n：不選。n 確實影響輸出 B 的大小，但本題單選著重的是計數表 C 的範圍 k；若問總空間就要同時算 n＋k。
D．參數 k (數值範圍)：選這項。C 必須涵蓋整個鍵值範圍，所以大小直接隨 k 增加。

本題答案：D。

## L6-026

如果所有輸入元素皆為 1 到 k，計數排序(Counting Sort)的時間複雜度為？

核心觀念：
把四段工作分開算：初始化 C 要 k 格 → Θ(k)；掃描 A 計數要 n 次 → Θ(n)；累積 C 要 k 次 → Θ(k)；由右往左回填 B 要 n 次 → Θ(n)。加起來 Θ(k＋n＋k＋n)＝Θ(n＋k)。迴圈是一段接一段，不能把 n 和 k 相乘。

選項判讀：
A．Θ(n + k)：選這項。同時計入掃描 n 筆資料與處理 k 種鍵值的成本。
B．Θ(k log k)：不選。這個流程沒有比較排序的對數分割；仍須掃描 n 筆資料，不能只有 log n，也不需要乘上 log n。
C．Θ(n log n)：不選。這個流程沒有比較排序的對數分割；仍須掃描 n 筆資料，不能只有 log n，也不需要乘上 log n。
D．Θ(n^2)：不選。沒有對所有輸入做雙層兩兩比較；這裡把先後執行的成本相加。

本題答案：A. Θ(n + k)。

## L6-040

計數排序（Counting Sort）要求輸入元素必須是？

核心觀念：
課本基本版本直接用鍵值存取 C[x]，因此 x 要是已知有限範圍的整數索引。例如數字 3 放到 C[3]；任意實數 3.7 不能直接當陣列下標。更一般的資料可以先取出／轉換整數鍵值，但那是額外的前處理，不是直接把任何物件都交給基本版本。

選項判讀：
A．字串：不選。這不是基本版本可直接拿來存取 C[x] 的有界整數鍵。
B．結構體：不選。這不是基本版本可直接拿來存取 C[x] 的有界整數鍵。
C．整數：選這項。有界整數可以直接對應計數表下標，符合基本版本的要求。
D．實數：不選。任意實數不能直接作為離散陣列下標；須先有額外的轉換與範圍條件。

本題答案：C. 整數。

## L6-054

當 k = O(n) 時，計數排序(Counting Sort)的時間複雜度為？

核心觀念：
先寫出一般式 Θ(n＋k)。k＝O(n) 表示存在固定常數 c，使得 k 不超過 c×n。於是 n＋k 不超過 (1＋c)n；另一方面掃描全部輸入至少要 n 次，所以總時間同時有線性上界與線性下界，得到 Θ(n)。不是看到兩個迴圈就相乘成 n²。

選項判讀：
A．Θ(n^2)：不選。沒有對所有輸入做雙層兩兩比較；這裡把先後執行的成本相加。
B．Θ(n log n)：不選。這個流程沒有比較排序的對數分割；仍須掃描 n 筆資料，不能只有 log n，也不需要乘上 log n。
C．Θ(n)：選這項。與上方成本推導相符：k＝O(n) 後，Θ(n＋k) 簡化為 Θ(n)。
D．Θ(log n)：不選。這個流程沒有比較排序的對數分割；仍須掃描 n 筆資料，不能只有 log n，也不需要乘上 log n。

本題答案：C. Θ(n)。

## L6-009

計數排序(Counting Sort)需要哪幾個輔助陣列？

核心觀念：
演算法有三個不同角色：陣列 A 是題目給的原始資料；陣列 B 是新建的排序結果；陣列 C 是新建的計數／位置表。因此「輔助陣列」是 B 與 C，A 不算額外建立。選項代號和陣列名稱是不同東西：例如選項 C 的內容可能才是「陣列 B」，判斷要看內容。

選項判讀：
A．A (輸入陣列)：不選。這是原本輸入 A，不是演算法額外建立的輔助表。
B．D (用於遞迴)：不選。課本這個版本沒有建立陣列 D，也沒有用遞迴表。
C．B (用於存放結果)：選這項。B 是存放排序結果的額外陣列。
D．C (用於計數)：選這項。C 是記錄次數與位置的額外陣列。

本題答案：C、D。

## L6-031

哪些情況下不適合使用計數排序(Counting Sort)？

核心觀念：
Counting Sort 用範圍換取速度。若只有 3 筆資料，最大鍵值卻是 10 億，基本版本仍要處理約 10 億格 C，通常非常浪費。它適合鍵值範圍受控的整數資料；一般浮點數與極少記憶體，都不適合直接套這個版本。

選項判讀：
A．鍵值為浮點數：選這項。任意實數不能直接作為離散陣列下標；須先有額外的轉換與範圍條件。
B．鍵值範圍 k 極大：選這項。與上方成本推導相符：k＝O(n) 後，Θ(n＋k) 簡化為 Θ(n)。
C．資料僅為整數：不選。有界整數正是適用條件，本身不是「不適合」的原因。
D．記憶體非常有限：選這項。需要額外的 C 與輸出 B，記憶體很有限時不適合。

本題答案：A、B、D。

## L6-064

計數排序(Counting Sort)的特性包含？

核心觀念：
特性要連同條件一起看：時間一般是 Θ(n＋k)，只有 k＝O(n) 才能說對 n 是線性；C 本身占 Θ(k)，加上 B 才是 Θ(n＋k)；標準「由右往左讀 A、先放入 B 再遞減 C」的版本是穩定排序。例：A 中兩個 2 分別標為 2甲、2乙，乙先被放到較右邊，甲後來放到左邊，結果仍是甲在乙前。

選項判讀：
A．線性時間複雜度：選這項。要加上 k＝O(n) 的條件；一般式是 Θ(n＋k)。
B．需要 O(k) 額外空間：選這項。這描述計數表 C 的額外空間；計入輸出 B 的總輔助空間仍是 Θ(n＋k)。
C．穩定：選這項。由右往左處理相同鍵值，先把後出現者放到右側，保留原本的相對順序。
D．適用於實數：不選。任意實數不能直接作為離散陣列下標；須先有額外的轉換與範圍條件。

本題答案：A、B、C。

j＝4：讀 A[4]＝0 → 查 C[0]＝1 → 第 10 行寫 B[1]＝0 → 第 11 行把 C[0] 減成 0。其他 C 格子不動。
j＝3：讀 A[3]＝3 → 查 C[3]＝10 → 第 10 行寫 B[10]＝3 → 第 11 行把 C[3] 減成 9。其他 C 格子不動。

j＝1：讀 A[1]＝2 → 查 C[2]＝6 → 第 10 行寫 B[6]＝2 → 第 11 行把 C[2] 減成 5。其他 C 格子不動。

⑥ 整理本題要填的 B 與 C
B＝0,0,0,1,1,2,2,2,2,3,3,3,4,5,5。
B 的每格都已實際寫入，不再有空格。
真正寫入數字 0 的格子是 B[1]、B[2]、B[3]。
因此第一格填 0,0,0,1,1,2,2,2,2,3,3,3,4,5,5；第二格填 0,3,5,9,12,13。兩個填空依題庫用 / 分隔，完整答案保留為 0,0,0,1,1,2,2,2,2,3,3,3,4,5,5/0,3,5,9,12,13。

⑦ 為什麼最後／中途的 C 不是一開始那一串
全部回填後，C[x] 等於原陣列中「嚴格小於 x」的元素個數。例如 C[0]＝0，不是原陣列沒有 0，而是沒有比 0 更小的元素。

本題版本條件：輸入含 0，因此驗算採 C[0..5] 全部初始化，累積由 i＝1 開始。若原題程式列出 i＝1 初始化、i＝2 累積，會漏掉 0；這裡只在解析標明計算條件，原題文字與答案都保留。
